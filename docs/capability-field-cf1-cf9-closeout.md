# CF1–CF9 Closeout — Actor × Environment × Institution Capability Foundations

Status: **COMPLETE**
Predecessor: CF0 problem-space freeze
Canonical compression: [`capability-context-doctrine.md`](capability-context-doctrine.md)

## 1. Programme result

CF1–CF9 completes the descriptive/causal Capability Field programme without creating the proposed Capability Field infrastructure.

The sequence contracted as follows:

```text
CF1 static topology
→ existing World ResourceFor / Actionability / Option / Capability is enough

CF2 capability identification
→ performance is evidence under tested conditions, not intrinsic Actor identity

CF3 institution mechanisms
→ M3 not rescued as predictive model; mechanism roles retained only for intervention/owner localization

CF4 production vs expression
→ prior exposure may change later Actor state, but “Environmental Capitalization” is a causal claim, not stock

CF5 selection/sorting
→ environment assignment and environment effect must be separated

CF6 coevolution
→ feedback survives only as family-specific directionally attributed hypotheses

CF7 transport
→ source evidence/structure does not become target truth without explicit mechanism assumptions

CF8 causal identification
→ claim strength is bounded by the actual causal query, design, assumptions and target

CF9 promotion
→ compress 14 semantic laws into one doctrine; reject all new universal objects/services/scores
```

## 2. Strongest positive result

The World model does need to reason about Actor, Environment and Institution together, but the correct integration is **causal and query-relative**, not object-centric.

The smallest durable topology is:

```text
owner-native Reality
        ↓
Actor boundary × transition × demand × as_of
        ↓
current owner-native relations/constraints
        ↓
ResourceFor / Actionability / Option / effective Capability
        ↓
Action / Effect / Outcome
        ↓
Attribution only if causally identified
```

History, selection and feedback enter only when the decision activates them.

## 3. Strongest negative results

### No Capability Field object

The name survives only as the research programme. The production concept is already expressible through existing relational Capability projections.

### No universal Institution object

Institutional mechanisms matter, but access, authority, incentive, enforcement, ownership, coordination and recovery remain owner/domain-native relations.

### No complete Environment state

Environment is an open, query-relative set of relevant exposures/conditions. Bounded decisions do not require pretending to possess complete closure.

### M3 remains rejected as a predictive family

CF0 found zero incremental static predictive cases over strong M2. CF3 recovered intervention-localization value only.

### No scalar Person/Environment/Institution decomposition

Observed variance, causal intervention effects, dynamic state formation and selection are different questions. The programme does not produce a universal percentage such as “X% individual, Y% environment.”

### No universal coevolution flywheel

Positive and negative feedback exist, but direction, mechanism, owner and causal attribution are family-specific.

## 4. What was promoted

CF9 promotes one compact doctrine document containing 14 semantic rules:

- relational capability;
- performance ≠ retained capability;
- Environment causal role;
- Institution causal role;
- static owner-native projection default;
- intervention-localizing mechanism decomposition;
- production ≠ expression;
- joint-system ≠ component capability;
- assignment ≠ exposure effect;
- causal query/design matching;
- explicit transport boundary;
- attributed feedback/co-evolution;
- descriptive ≠ normative institution evaluation;
- first-class UNKNOWN when the stronger claim is not identified.

## 5. What remains Research

Detailed CF mechanism roles, case matrices, evidence classes, transport postures, causal query taxonomies and family-specific feedback models remain research/evidence because they are activated only by particular questions.

They are escape hatches for reconstruction and falsification, not default Context.

## 6. Engineering result

The programme intentionally closes with:

```text
1 new compact canonical doctrine
0 production source changes
0 contract/schema additions
0 service/registry additions
0 persisted Capability/Environment/Institution/causal state primitives
```

This is a successful outcome, not an incomplete implementation. The research found that the required complexity belongs in **questions, evidence and owner-native causal relations**, not a new shared machinery layer.

## 7. Reopening conditions

Reopen CF research only when a real current workload demonstrates at least one of:

- existing owner-native Resource/Capability projection cannot represent a decision-relevant context distinction;
- compact doctrine repeatedly causes consequential Actor/environment/institution misattribution;
- CF3 mechanism decomposition cannot localize a repeated intervention/owner failure;
- a dynamic capability-production claim requires a shared representation that at least two materially different owners cannot hold locally;
- selection/transport/causal-admission logic recurs as missing executable responsibility rather than reasoning method;
- a family-specific coevolution mechanism independently recurs across materially different domains with the same missing shared owner responsibility.

Historical conceptual interest alone is not a reopen trigger.

## 8. Normative handoff

CF0–CF9 intentionally stops before asking which institution *should* be chosen.

A future normative-design programme may compare output, autonomy, fairness, distribution, resilience, option value, safety, maintenance and recovery, but it must inherit the descriptive causal boundaries here and must not collapse those plural objectives into one hidden quality scalar by default.
