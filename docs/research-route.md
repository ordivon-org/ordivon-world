# Link Research Route — Connectivity and Evidence Continuity

## Route change

The previous route treated a programmable Network World as the long-term
Agent-native center. The revised route treats it as a useful experiment
laboratory and moves the core research question upward:

> How does an open Task express, select, verify, change, and recover logical
> communication relationships while preserving identity, path-conditioned
> evidence, uncertainty, and continuity?

## L0 — Preserve operational truth

Retain useful path/service observations, reduced history, explicit isolated
egress, and bounded reference experiments.

Non-goals:

- no general network platform;
- no automatic route or VPN control;
- no expansion of Baseline into a proxy product;
- no promotion of Network World into production infrastructure.

## L1 — Host-consumable observations

Publish secret-free observations with:

- logical source and target labels;
- method and protocol;
- path/route class and egress condition;
- endpoint/application result;
- identity evidence where available;
- timestamp, freshness, uncertainty, and invalidation condition.

Prove that Host Context can consume these facts without Link owning Context or
Task state.

## L2 — Connectivity Requirement field derivation

Use two workloads:

1. public Web research across direct, VPN, and remote Edge paths;
2. Agent-to-Agent or service Artifact review with identity, delivery, reply, and
   handoff state.

Delete candidate fields until only cross-workload, failure-preventing fields
remain. Do not automate network mutation.

## L3 — Path-conditioned evidence

Observe the same logical target across materially different paths. Preserve all
historical Artifacts while preventing one path-specific observation from
becoming universal truth. Define still-valid, conditionally-valid, expired,
superseded, and re-verification-required states.

## L4 — Recovery under change

Inject:

- response loss after acceptance;
- endpoint replacement;
- certificate or identity rotation;
- direct-to-VPN or direct-to-Edge path replacement;
- synchronous-to-asynchronous communication change;
- participant handoff.

Reconcile original delivery/reply state before retransmission and preserve the
parent Task.

## L5 — Network World falsification

Use mature namespace, CNI, service-mesh, SDN, and traffic-control mechanisms for
controlled experiments. Retain a Link-native Network World only if multiple
workloads require shared Task-conditioned identity, reset, evidence, and
invalidation semantics above those mechanisms.

## Decision outcomes

- **promote** compact Connectivity/Binding/invalidation semantics;
- **absorb** them into Host or observation adapters if no independent layer is
  needed;
- **freeze** Network World and Baseline as research references;
- **delete** abstractions that merely rename topology, traces, or endpoints;
- **retain** operational observations and private tools independently of the
  research outcome.
