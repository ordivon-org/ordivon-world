# Research Route

## W0 — completed

W0 classified 16 inherited carrier groups as `retain`, `adapter-only`, `historical`, or `delete-candidate` and froze the first experiment without admitting an inherited Edge or Link schema.

See [`w0-carrier-inventory.md`](w0-carrier-inventory.md).

## W1 — completed; direct integration won

W1 compared direct Host integration with the same path plus a hash-chained World correlation journal. Both arms survived post-commit/pre-admission response loss, resumed in a fresh process, queried the original Receipt, verified the exact Artifact, and completed one Task exactly once. The journal added six events and 4,535 bytes while reducing no Host or provider state.

Decision:

- do not retain an independent World correlation layer;
- keep Host semantic lifecycle unchanged;
- keep provider-native reliability in provider adapters;
- bind source-native observations through Host StateRefs.

See [`w1-results.md`](w1-results.md).

## Capability Program v0 — completed through WXP-2

The post-W1 program added capability without reopening the rejected World layer:

- WCP-0: adapter-local capability declarations and a generated read-only portfolio;
- WCP-1: real research-source and provider-acceptance consumers;
- WCP-2: Cloudflare Workflow durable evidence runs with private R2 manifests;
- WXP-1: callback wake-up plus provider inspect fallback under seven delivery faults;
- WXP-2: provider-to-R2 Artifact movement compared with Host byte proxying;
- W-A1: deletion and promotion decision.

The live WCP-2 run survived Host-process replacement through the original Workflow handle, verified all five Artifacts, produced no unsafe redispatch, duplicate instance, false completion, or World database record, and required no Task-recovery operator intervention.

WXP-1 localized callback generation and deduplication to Host and the adapter. WXP-2 retained provider-native R2 movement and Artifact references. Neither experiment earned shared World state.

See [`wcp0-wxp2-results.md`](wcp0-wxp2-results.md).

## W2 — conditional and inactive

Callback discontinuity and remote-to-remote Artifact movement were tested directly and did not reproduce an unowned responsibility. W2 therefore remains inactive.

W2 activates only if a future trajectory reproduces one exact failure caused by provider capability mismatch, provider contract drift, participant handoff, or a valid need to rebind one still-open Effect. Any activation must compare direct source-native integration with the smallest explicit capability or binding decision. No marketplace, universal broker, automatic routing, or blind redispatch is authorized.

## WCP-3 — deferred

A second external capability class is not required to keep the completed program open. It may begin only from a named real workload with substantial capability gain and architectural contrast, such as a programmable Sandbox, A2A remote Agent, model-provider background job, or asynchronous human/institutional participant.

Selection by roadmap sequence or API convenience is insufficient.

## Current portfolio disposition

The repository retains:

- the production Cloudflare provider;
- the network-observation module;
- adapter-local capability declarations;
- generated evidence and bounded experiments;
- historical Edge and Link carriers where deletion would falsify provenance or break private operations.

The top-level World semantic layer, service, database, broker, router, Workflow engine, callback authority, and Artifact transfer service remain absent.

Future architecture work begins from a named failure, not from the existence of provider, network, transport, Node, or historical World code.
