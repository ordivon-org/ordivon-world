# CF2 — Capability Identification: State, Support and Performance

Status: **COMPLETE**

## 1. Capability is not directly observed

CF1 showed that effective Capability is already a bounded supported-transition relation. CF2 asks what evidence justifies moving from an observed episode to a capability claim.

The critical separation is:

```text
realized performance
!= situated capability
!= joint-system capability
!= retained independent Actor capability
!= transfer capability
!= verification/intervention capability
!= recovery capability
```

These are not seven mandatory fields. They are different questions that become active only when a decision depends on them.

## 2. Evidence rule

A performance episode is evidence for the conditions actually tested.

```text
Actor A + Tool T + Environment E + Institution I
→ succeeds on transition τ at time t
```

supports a bounded claim about that supported system under those conditions. It does **not** by itself establish:

```text
A alone can do τ
A transfers τ to E2
A retains τ after T disappears
A learned τ because of T
A is globally “more capable” than B
```

## 3. Stronger claims require discriminating variation

When the decision really depends on retained Human/Actor capability, useful evidence can include:

- unassisted reconstruction;
- support removal;
- transfer to a varied environment/tool;
- seeded-error detection;
- recovery after expected aid disappears;
- repeated performance after time has passed;
- independent reproduction under another owner boundary.

The exact probe should be chosen by the claim, not by a standing capability battery.

## 4. Capability unmasking does not earn a primitive

The intuitive concept survives, but only as a derived causal description:

```text
retained substrate evidence roughly stable
+ current environment/institution changes exercisability
→ expression / masking / unmasking change
```

If the retained substrate was never measured, CF2 does **not** permit the phrase “unmasked latent capability” to become a fact. The supported answer may be only:

> performance changed under a changed support relation; whether retained Actor state changed is UNKNOWN.

## 5. Production is not expression

A later improved outcome after a richer environment has at least three live explanations:

```text
A. current expression improved
B. prior exposure changed Actor state
C. selection/common causes changed who received the exposure
```

CF2 can distinguish A from a strong retained-state claim only with discriminating evidence; B belongs to CF4 and C to CF5.

## 6. No universal independence objective

A joint Human–Agent system can be legitimately more capable than the unaided Human. Requiring every capability to be independently reproducible would discard real system capability.

Conversely, treating joint output as retained Human skill creates false resilience claims.

The correct boundary is purpose-dependent:

```text
production task        → joint capability may dominate
verification task      → intervention capability may dominate
provider-loss risk     → recovery capability matters
education/transfer     → retained/transfer capability matters
```

## 7. CF2 result

The smallest reusable rule is:

> **Capability claims inherit the boundary, conditions, transition, horizon and evidence of the observations that support them. Do not promote realized performance to a stronger Actor capability claim unless a decision-relevant probe actually distinguishes the stronger claim. Preserve UNKNOWN when production, expression and selection remain observationally confounded.**

No `CapabilityState`, capability score, standing battery or unmasking object is earned.
