# World / Reality Research

This directory is the **first lookup for Ordivon World / Reality research**. It is a navigation and status layer over the detailed research corpus; it does not replace, rewrite, or delete the underlying WDF/TSA evidence.

## Owner / scope / authority

**Research owner:** World / Reality.

World / Reality owns cross-domain research semantics for claims about independently authoritative Reality, including actuality/model firewalls, generic modal claim structure, causal claim/query/grounding/validation structure, property-evaluation semantics, temporal target-structure semantics, and thin cross-regime research grammar where needed.

It does **not** own a complete ontology of Reality and does not absorb domain-specific mechanisms. Runtime owns execution; Network owns communication/reachability realization; Host owns Task/coordination authority; Harness owns Agent-support/cognition; Human, Finance, Game, Media and other domain owners retain their domain semantics; providers and external domains retain native truth.

**Research authority is not production authority.** The production `ordivon-world` package remains the narrower owner-preserving external adapter/trajectory boundary described by [`../../../README.md`](../../../README.md), [`../../../ARCHITECTURE.md`](../../../ARCHITECTURE.md), and [`../../../STATUS.md`](../../../STATUS.md). Research results constrain reasoning and engineering consumption but do not automatically become product schemas, services, registries, or APIs.
