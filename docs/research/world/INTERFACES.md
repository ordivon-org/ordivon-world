# World Research Interfaces

World / Reality is a semantic research owner, not a universal authority hub.

| Boundary | World / Reality owns | Other owner retains |
|---|---|---|
| Runtime | Reality-level distinctions relevant to execution claims | Workspace/Job/Attempt/process execution and target mechanics |
| Network | generic Reality semantics needed to state claims | communication, forwarding, reachability realization, convergence and network-local truth |
| Host | Reality semantics that constrain work claims | Task, Effect, Dispatch, revision fencing, coordination authority, Verification/completion |
| Harness | Reality/evidence distinctions used by Agent research | bounded Agent cognition, model/tool loop, Run/Step evidence |
| Domain owners | cross-domain claim grammar where genuinely shared | Human/Finance/Game/Media/etc. domain mechanisms and native semantics |
| Providers/external domains | binding/provenance semantics where World product participates | native occurrence, currentness, remote state, native receipts and capability truth |

## Required firewalls

- Reality truth != model projection.
- Causation != responsibility or operational ownership.
- Temporal precedence != causation.
- Evaluation validity != normative desirability, fairness, or policy choice.
- Historical evidence != current external state.
- Delivery != cognition.
- Provenance != universal authentication.
- A research bridge grammar != a global owner registry.

No constitutional owner conflict was found during consolidation. Any future owner split requires concrete responsibility conflict or duplicated semantic authority, not aesthetic preference.
