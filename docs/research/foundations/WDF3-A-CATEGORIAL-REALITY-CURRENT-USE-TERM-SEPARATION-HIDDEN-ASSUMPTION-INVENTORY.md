# 1. Why WDF3-A is necessary

The whole-domain coverage search found that many apparently later World questions silently presuppose categorial commitments.

Examples:

```text
"mass causes ..."             assumes a property/quantity bearer
"water is H2O"                assumes a kind/identity relation
"the law relates quantities"  assumes quantity/property structure
"this fact grounds that fact" assumes fact + grounding categories
"the storm persisted"         assumes event/process identity
"the account owns the asset"  assumes institutional status/fact
"the model state differs"     assumes description difference may matter to Reality
```

WDF0 prevents many destructive collapses, but intentionally does not provide a complete positive ontology.

Therefore WDF3 asks:

> Which distinctions are required to make heterogeneous Reality claims without treating grammar, database schemas, formal variables, scientific models or institutional representations as Reality itself?

# 2. The first meta-distinction: category vocabulary has multiple truth roles

The word `category` itself is ambiguous.

At least five roles appear in current practice:

```text
1. Linguistic category
   noun / verb / predicate / mass term / count noun / tense / aspect

2. Conceptual category
   a distinction used by cognition or inquiry

3. Representational/model category
   variable type / state-space dimension / class label / ontology schema

4. Institutional category
   legally or procedurally constituted type/status

5. Reality-facing ontological category candidate
   a claim that Reality itself contains or instantiates a distinction
```

### Anti-collapse A0

```text
CategoryInLanguage
!= CategoryInConceptualScheme
!= CategoryInModelOrSchema
!= InstitutionalCategory
!= OntologicalCategory
```

A correspondence may hold.

Identity is never automatic.

This is the foundational firewall for WDF3.

# 4. `Object / Substance / Continuant` versus `Process / Event / Occurrent`

Current language often contrasts:

```text
objects/things that exist or persist
vs
processes/events that happen or occur
```

This distinction has real explanatory use.

But WDF3-A finds four hidden assumptions if it is promoted too quickly:

```text
H1. Every Reality bearer is either an object or an event.
H2. Objects are ontologically prior to processes.
H3. Processes are merely sequences of object states.
H4. The object/process distinction is context-free and cross-scale invariant.
```

None is established.

Matched cases:

```text
storm
chemical reaction
organism
flame
traffic jam
running computation
financial transaction
institutional procedure
persistent Agent service
```

can often be individuated more naturally by organized histories/activities than by fixed component sets.

Yet many ordinary material continuants remain usefully object-like.

### Provisional separation

```text
Continuant-role:
  identity is tracked through a history while the referent is treated as persisting.

Occurrence-role:
  identity is tracked as something happening/unfolding over an interval/history.
```

This is role language, not a final two-category ontology.

### Anti-collapse A3

```text
Process != OrderedListOfStaticStates by default
```

### Anti-collapse A4

```text
Object != FixedComponentSet
```

already compatible with WDF0.

### Anti-collapse A5

```text
OccurrenceRepresentation != OccurrenceItself
```

An event log is not the event.

# 34. Compressed conclusion

WDF3-A finds that the main categorial danger is not having too few nouns; it is **confusing the categories of our descriptions with the categories of Reality**.

A database schema may contain an `entity`, a model may contain a `state`, a language may contain a predicate, a classifier may output a class, a sensor may output a number, a ledger may contain a record, and a physical theory may contain mathematically distinct states. None of those representation facts by itself establishes that Reality contains a corresponding entity-kind, state-kind, property, natural kind, magnitude, fact or distinct physical situation.

The first surviving WDF3 structure is therefore not a new furniture list but a typed set of categorial questions: what is being individuated, characterized, classified, said to obtain, treated as dependent, quantified, realized, regarded as equivalent, or claimed absent—and relative to which legitimate criterion and regime.

The decisive next step is matched falsification, not metaphysical commitment.
