# 1. Matched-case discipline

Each case asks:

```text
1. What actually happened?
2. What counterfactual contrast is intended?
3. Does intervention on X change Y?
4. Is there an actual productive/process path from X to Y?
5. Does X change the probability of Y?
6. Is X an actual/token cause of this Y-token?
7. Is X direct or only on a causal path?
8. Is the role productive, preventive, enabling or sustaining?
9. Does verdict depend on normality/reference/contrast?
10. Does verdict depend on model/grain?
11. Does the relation transport to nearby regimes?
12. Which causal theory would lose information here?
```

A theory is not rejected merely because it needs extra machinery. It is rejected as a universal reduction only when the extra machinery reconstructs a distinct causal role it originally claimed to eliminate.

# 2. B1 — Common-cause association without target causation

Structure:

```text
Atmospheric state S -> barometer reading B
Atmospheric state S -> rain R
```

Suppose B strongly predicts R.

Matched verdicts:

```text
Association(B,R)             YES
PR observationally           YES possible
CF simple                     can appear YES under naive comparison
SI do(B) -> R                NO under valid intervention semantics
MP B-produces-R              NO
PT B-to-R path               NO
AC B caused this rain        NO
```

### B1 result

```text
Association / predictive probability change
!= Causal influence
```

and:

```text
ProbabilityRaisingByObservation
!= CausalEffect
```

A causal account must distinguish intervention-relevant structure from common-cause correlation.

This case eliminates pure regularity/correlation as a universal causal truth criterion.

# 4. B3 — Early preemption

Canonical structure:

```text
Suzy throws rock S
Billy throws rock B
Suzy's rock arrives first and shatters bottle Y
Billy's rock would have shattered Y if Suzy had not
```

Actual history contains one realized shattering path through S; B's backup process is preempted.

Verdicts:

```text
CF simple S-but-for-Y          NO
SI naive remove-S only        NO if backup remains
SI structured contingency     can recover S relevance
MP S productive connection    YES
PT S actual path              YES
AC S actual cause             strongly YES in target judgment
AC B actual cause             typically NO / preempted
PR S                          not discriminating
NR/MG                         materially relevant in structural accounts
```

Halpern–Pearl-style actual-causation work introduces contingencies/structural information precisely because simple but-for dependence is inadequate in preemption-style cases.

### B3 separation

```text
ActualProductivePath
can survive
while NetButForDifference disappears.
```

Therefore:

```text
SimpleNetDifferenceMaking
is NOT necessary for actual cause.
```

But this does not establish production as sufficient for every causal query.

# 5. B4 — Symmetric overdetermination

Structure:

```text
A fires lethal shot
B independently fires lethal shot
both arrive so that either alone would suffice for death Y
```

Matched verdicts:

```text
CF A-but-for-Y          NO
CF B-but-for-Y          NO
SI remove A alone       no outcome change
SI remove B alone       no outcome change
MP/PT A->Y              YES candidate
MP/PT B->Y              YES candidate
AC A                    strong candidate YES
AC B                    strong candidate YES
```

### B4 result

Overdetermination sharpens B3:

```text
Actual productive contribution
!= Net outcome difference under single-factor removal
```

A theory that only recognizes net difference-making can erase simultaneously sufficient actual contributors.

Conversely, a production-only theory still needs a selection rule to distinguish causally relevant participants from every physical process in the scene.

# 6. B5 — Difference-making without ordinary positive production: double prevention

Abstract structure:

```text
P would prevent Y
X prevents P
therefore Y occurs
```

For example, an action disables an inhibitor that otherwise would block a target process.

Verdicts:

```text
CF X-to-Y             YES can hold
SI do(X) vs not-X     YES
MP direct X-produces-Y ordinary sense   weak/NO
PT continuous X->Y productive transfer  may be absent
AC X                  disputed / query-sensitive but often causally relevant
PE X                  prevention-of-prevention
```

### B5 result

This is the mirror image of preemption/overdetermination.

```text
Strong DifferenceMaking
can occur
without ordinary positive production from X to Y.
```

Therefore:

```text
Production/Transmission
is NOT a universal necessary condition
for every legitimate difference-making causal claim
```

unless the theory expands `production` so broadly that it simply renames dependence/prevention.

That expansion must then be made explicit rather than treated as reduction.

# 8. B7 — Prevention


Verdicts:


### B7 result



```text
promotes / prevents / enables / sustains
```

without reifying those words as four universal causal primitives.

# 57. Final compressed judgment

WDF4-B falsifies the idea that the causal architecture can be discovered by choosing one familiar causal signal and universalizing it.

Correlation and observational probability fail under common causes. Simple but-for dependence fails under preemption and overdetermination. Probability raising is neither sufficient nor necessary across type/token and reference-class changes. Intervention/invariance is exceptionally strong for causal-effect and control questions but does not by itself reveal mechanism or solve token actual-cause selection. Mechanism/production and actual process paths are indispensable in many token cases but do not naturally cover omissions, double prevention, prevention targets or causal effects whose mechanism remains unidentified. Structural actual-cause models handle difficult token cases but remain model/normality/grain relative and do not replace effect or mechanism theory. Physical process/transmission accounts remain strong local candidates but do not yet survive cross-regime universality without bridge-dependent semantic loss.

The matched cases instead expose two independently variable causal dimensions at the current evidence frontier:

```text
Causal influence / difference-making under admissible contrast
```

and:

```text
actual productive/process/path realization in history.
```

Preemption and overdetermination show production without simple net difference-making. Double prevention and omission show strong difference-making without ordinary positive production. Ordinary mechanisms and maintenance can exhibit both. Common-cause proxies exhibit neither.

A third unresolved problem then becomes visible: actual/token-cause selection. Actual cause is not automatically identical to either axis. It can require actual path participation, structural contingencies, redundancy/preemption handling, contrast, normality and model/grain provenance.

This does not yet prove causal dualism or pluralism. It proves a representation/foundation burden: any unified causal ontology must reconstruct these independent distinctions without loss. The next task is therefore architecture reconstruction, not another inventory.

WDF4-C is admitted exactly to compare a difference-making monism, production monism, dual-aspect/two-axis architecture, typed causal pluralism, thin common core with domain-local realizations, and query-first compression. Only that destructive reconstruction can decide whether WDF4 has a positive causal core strong enough to approach Foundation v1.
