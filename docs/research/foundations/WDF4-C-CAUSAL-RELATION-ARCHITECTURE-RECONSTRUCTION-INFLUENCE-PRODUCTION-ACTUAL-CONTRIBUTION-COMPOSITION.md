# 1. R1 — Enriched Difference-Making Monism

Core ambition:

```text
All causation reduces to sufficiently sophisticated
counterfactual/interventional/invariance-sensitive difference-making.
```

A sophisticated R1 need not use simple but-for dependence. It may use:

```text
structured interventions
contingencies
path-specific contrasts
normality/defaults
multi-locus alterations
probabilistic effects
reference classes
model refinement
```

This makes R1 much stronger than the simple form already rejected in B.

## 1.1 Strengths

R1 handles naturally:

```text
B1 common-cause discrimination
B5 double prevention
B6 omission
B7 prevention
B8 maintenance under removal
B9 randomized type effects
B10/B11 probabilistic separation
B12 contrastive cause/background
B13 mediation
B21 transport/invariance
```

WDF2 supplies unusually strong infrastructure for this route.

## 1.2 Preemption and overdetermination

Enriched R1 can recover causal relevance through contingencies such as:

```text
remove candidate cause
+ hold/prevent backup route appropriately
```

This handles B3/B4 better than simple but-for.

But the contingency only works because the model already distinguishes:

```text
actual active route
backup route
preempted route
relevant intermediate structure
```

Thus actual-history/path information is not eliminated.

## 1.3 Destructive test

Construct two causal models with equivalent target intervention effects for X and Y, but different actual internal routes:

```text
M1 actual history: X -> A -> Y
M2 actual history: X -> B -> Y
```

For total effect query:

```text
CIP(M1) = CIP(M2)
```

can hold.

But for mechanism, failure localization, directness under refinement, actual path and intervention-on-mediator queries:

```text
M1 != M2
```

Therefore a pure influence profile loses actual realization truth.

### C-R1-F1

```text
SameInfluenceProfile
!= SameActualProductionProfile
```

If R1 adds actual-path/production structure to repair this, it becomes layered rather than genuinely one-axis.

### R1 disposition

```text
EnrichedDifferenceMaking
= RETAINED AS MAJOR CAUSAL PROJECTION
= REJECTED AS COMPLETE REDUCTION UNLESS IT IMPORTS ACTUAL REALIZATION
```

# 3. R3 — Dual-Aspect / Two-Axis Architecture

Core ambition:

```text
Causal reality has two distinct aspects:
Influence / Difference-Making
and
Actual Production / Path
```

This matches the strongest B result.

## 3.1 Weak interpretation — coordinate duality

Under a weak interpretation:

```text
InfluenceAxis != ProductionAxis
```

means only:

```text
one causal situation may require two non-equivalent projections.
```

This is directly supported by B.

## 3.2 Strong interpretation — ontic dualism

Under a strong interpretation:

```text
Reality contains two fundamentally different causal relations.
```

B does not establish this.

Why not?

Because the matched cases only establish extensional and explanatory non-identity at current resolution. They do not establish distinct ultimate truthmakers.

A single deeper structure might yield:

```text
cross-alternative influence projection
and
actual-history realization projection.
```

## 3.3 Historical pressure

Hall's dependence/production distinction is an important predecessor: dependence and production can diverge in omission, preemption and related cases.

But conceptual/evidential separation does not entail ontic causal pluralism. Later mechanism/difference-making integration proposals explicitly exploit this gap.

### R3 disposition

```text
CoordinateDuality = STRONGLY RETAINED
OnticTwo-Causations = NOT EARNED
```

The weak R3 therefore converges toward R5.

# 4. R4 — Typed Causal Plural Family

Core ambition:

```text

```

```text

```

## 4.1 Strength

R4 can fit nearly every case by giving it the appropriate type.

## 4.2 Destructive weakness — unconstrained accommodation

A foundation architecture is not successful merely because it can assign a new relation type whenever an old one fails.

If each hard case creates another causal primitive:

```text
coverage rises
compression falls
composition becomes opaque
cross-regime transport becomes ad hoc
```

## 4.3 Distinctional vs definitional pluralism

A critical separation is:

```text
Many distinctions inside causal reasoning
!=
Many definitions / fundamental causal relations.
```

The B battery clearly establishes the first.

It does not yet establish the second.

## 4.4 Composition problem

Suppose:

```text
X prevents P
P produces Y
```

If `prevention-causation` and `production-causation` are independent primitives, what licenses the composite claim:

```text
X caused Y?
```

R4 requires explicit composition laws anyway.

Once those laws appeal to shared transition/influence/history structure, a common architecture reappears.

### R4 disposition

```text
TypedPluralism = LIVE FALLBACK
IrreducibleOnticPluralism = NOT EARNED
```

Plural relation types may still emerge from D+ grounding pressure, but C does not promote them.

A causal claim concerns a directed role in the realization or alteration-sensitivity of a target transition/outcome/persistence pattern, under a declared validity envelope and contrast, while remaining distinct from mere association, constitution, representation, authority, explanation and evidence.

Provisional compression:

# **Thin Causal Commonality — TCC-alpha**

A causal situation supports Reality-constrained,
directed transition relevance to a target,

### Important status

NOT a reductive truthmaker theory
NOT a universal binary CAUSES relation

# 52. Final compressed judgment

WDF4-C does not find evidence for a single universal `CAUSES` relation, but it also does not find evidence that causation is merely a loose word for unrelated domain-specific phenomena.

The matched distinctions from B survive reconstruction most economically as two projections inside a thinner causal situation architecture:

```text
MIP — Modal Influence Projection
     What difference does X make to Y across declared admissible alternatives?

ARP — Actual Realization Projection
     What path/process/mechanism/blocking/sustaining structure was actually realized in history?
```

These projections are not extensionally identical. Preemption and overdetermination separate actual production from simple net influence. Omission and double prevention separate strong influence from ordinary positive production. Randomized effects separate type-level MIP truth from unknown token ARP. Mechanism-known cases separate rich ARP from unresolved actual-cause selection.

However, this does not force two ontic causal relations. A single Reality situation can have a modal projection across alternatives and a historical realization projection in the actual trajectory. Thus the strong Hall-style two-causations reading is not currently earned; coordinate duality is.

Actual/token cause is likewise not promoted to a third primitive. The current best model treats an actual-cause judgment as a derived, criticizable verdict over the typed causal situation: actual history, MIP, ARP, preemption/redundancy, contrast, normality, model/grain and negative/preventive roles. Derived does not mean subjective.

This yields the current leading architecture:

```text
Thin Common Causal Architecture
+
Typed Domain-Local Realization
+
Query-Specific Derived Actual-Contribution Verdicts
```

It beats simple difference-making monism because actual realization is not recoverable from total influence alone. It beats simple production monism because omissions, prevention, type effects and transport require modal/contrastive structure. It beats strong ontic dualism because two projections do not prove two fundamental truthmakers. It beats unconstrained pluralism because the same architecture recurs across regimes. It beats complete eliminativism because cross-regime causal commonality is real and reusable.

But C deliberately stops before claiming a completed causal metaphysics. The architecture still labels MIP and ARP as causal without yet giving a non-circular grounding of causal status or direction. Intervention can presuppose causal isolation; mechanism can presuppose production; powers can be individuated through manifestations; structural equations can presuppose oriented causal interpretation; temporal and thermodynamic arrows may not be identical to causal direction.

Therefore the next foundation problem is no longer `which causal architecture covers the cases?` It is:

```text
What grounds causal direction and causal status,
and where—if anywhere—must causation remain primitive?
```

That is the exact task of WDF4-D.


# 53. Note on current architecture strength

WDF4-C's provisional winner should be read with one final precision:

```text
TCSA-alpha does not claim that every valid causal claim must have both MIP and ARP fully known.
```

Rather:

```text
Type/effect/invariance query
may be valid with strong MIP and unknown ARP.

Mechanism/path query
may be valid with strong ARP while broader MIP remains incomplete.

Actual-cause query
normally requires a typed selection over whichever MIP/ARP/history information is relevant to that query,
with UNKNOWN preserved where the required coordinate is unidentified.
```

Thus TCSA is not a conjunctive criterion:

```text
Cause iff MIP AND ARP
```

Such a criterion would wrongly erase randomized causal effects with unknown mechanisms and omission/prevention cases without ordinary positive production by the candidate factor.

The architecture instead states:

```text
CausalQuery determines which causal projections are truth-relevant;
Reality and evidence determine whether those projections obtain.
```

This preserves CTQI-alpha rather than undoing it.
