# 3. Pre-category target specification

A category candidate cannot be tested against literally category-free Reality descriptions; any inquiry uses some inherited vocabulary.

So D rejects an impossible purity requirement:

```text
ValidTargetScope requires zero prior ontology
```

Instead it requires **candidate independence**.

# Candidate-Independence Test

A target scope S is admissible for testing category K only if:

```text
Remove K and its defining predicates from the description.
Replace K with neutral identifiers, measurable/interaction conditions,
previously admitted background relations, or physical/institutional coordinates.

If S remains re-identifiable for the experiment/inquiry,
then S does not viciously presuppose K.
```

### Examples

Instead of:

```text
"all members of species K"
```

start with:

```text
sampled organisms/lineages/populations under explicit space-time/gene-flow/ecological data.
```

Instead of:

```text
"valid contracts"
```

start with:

```text
specified agents, utterances/documents/actions, rule/history corpus and jurisdictional facts.
```

Instead of:

```text
"particles in this regime"
```

start with:

```text
energy/length scale, preparation/interaction conditions and theory/evidence domain.
```

### Anti-law D1

```text
BackgroundVocabularyDependence != ViciousCategoryCircularity
```

The test is whether the target can still be located if the candidate category fails.


# 45. Final compressed judgment

WDF3-D falsifies the weakest part of WDF3-C: a category cannot be admitted by first declaring the `regime` in which it is valid, because that regime can silently presuppose the category itself and can become an unfalsifiable escape hatch. The repair is scope-first rather than regime-first. Identify a target without relying on the candidate category, test a criterion against Reality, then derive the category's Categorial Validity Envelope from the conditions and transformations under which the criterion remains stable.

This allows objective pluralism without relativism. Two category systems can both be objective over the same underlying target when they ask materially different questions or use different Reality-grounded criteria, grains or validity envelopes. They cannot both be declared true merely because their vocabularies differ: same-target, same-role, same-criterion, same-envelope contradictions remain genuine disagreements.

D also exposes the first major compositional weakness of the entire WDF3 reconstruction. Local category truth is not enough. Reality crosses scales and regimes through realization, constitution, composition, abstraction, implementation, causal coupling and institutional mediation, and these bridge relations are not generically transitive. A valid World model therefore needs typed bridge paths with explicit composition conditions, invariants and loss—not one generic `depends-on` edge.

The strongest architecture candidate is consequently revised from Global Minimalism / Local Pluralism to **Global Minimalism / Validity-Bounded Pluralism**. No substantive category—not Object, Process, Property, Kind, Fact, Relation, Structure, Information, System, Constraint or Dependence—earns promotion to global World furniture at the current evidence frontier. What remains universal is the research/claim discipline, not a universal furniture table.

The next upstream falsifier is therefore WDF3-E: whether typed cross-regime bridge relations can be composed coherently without either collapsing their truth roles or forcing a new universal Grounding/Building ontology.
