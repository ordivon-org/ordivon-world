# 6. Freshly exposed residual-map omissions / possible unknown continents

The following are not yet admitted as foundations. They are **coverage discoveries** that do not fit cleanly into the current named residual map.


```text

```

Potential importance: **cross-cutting and presently homeless**.

## U2 — Phenomenal / first-person / perspectival Reality

Human and Media can own cognition/perception, but the World referent still faces a generic question:

```text
Are first-person / perspectival facts merely reports/representations,
or are there Reality facts whose truth conditions are essentially perspective-indexed?
```

Pressure includes:

```text
phenomenal experience
indexical location/time/self
embodied viewpoint
observer-relative but objective relational facts
machine/Agent internal perspectives
```

WDF0's `Relative != Subjective` and WDF3's CVE help but do not close the domain.

## U3 — Open-ended ontology change / category genesis

`Self-modifying structures` is too narrow for regimes where the ontology available to participants changes historically.

Examples:

```text
new biological functions/kinds arising through evolution
new institutional statuses created by legislation
new software object types/protocol capabilities
new synthetic-world entity classes
Agent ecologies inventing categories/rules that later become causally operative
```

Question:

```text
Can Reality's locally valid category inventory itself evolve without assuming a fixed higher-level furniture list?
```

This directly pressures any static World schema while remaining compatible with WDF3's thin research grammar.

## U4 — Mutual constitution / circular dependence / co-emergence

WDF3-L established that cycles are not automatically vicious, but did not build a theory of constructive mutual dependence.

Pressure cases:

```text

institution ↔ participant practice
market ↔ price expectations
protocol ↔ compatible participants
language ↔ use community
Agent population ↔ governance regime
observer ↔ instrument calibration ecology
```

Potential issue:

```text
A and B may be jointly stabilized without either being absolutely prior.
```

This is not exhausted by one-way grounding, causation or constitution.

## U5 — Record / trace / memory formation as a Reality process

Current work separates evidence from Reality, but not the physical and institutional formation of durable traces.

Cross-cutting pressure:

```text

logs/ledgers
institutional records
Agent memory/checkpoints
```

Question:

```text

```

This may bridge Time, Thermodynamics, Measurement, Information and Causation without reducing to any one of them.

## U6 — Resource / conservation / exchange / flow ontology
