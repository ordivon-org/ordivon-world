# WDF1-G — Modal Architecture Reconstruction / Falsification / Closeout

Status: complete. **WDF1 Modal Architecture v1 is frozen at the research level.** TARA survives only as a **typed modal claim/question grammar**, not as a Reality ontology and not as a production schema. Derived convenience nouns are demoted where deletion succeeds. Law metaphysics, objective chance, counterfactual generation and causation remain explicit open interfaces. Exact next major round admitted by residual ranking: **WDF2 — Counterfactual Architecture**. Its exact first canonical sub-round is **WDF2-A — Counterfactual Current-Use / Term Separation / Hidden-Assumption Inventory**.

WDF0 Meta-Foundation v1 remains frozen. No WDF0 reopen condition fired. No production refactor is admitted by this closeout.

---

## 0. Purpose

WDF1-B–F expanded and separated the modal field:

```text
A — matched modal separation
B — architecture rivals / TARA reconstruction
C — law / initial / boundary / constraint separation
D — reachability / control / intervention / Capability reconstruction
E — epistemic probability / chance separation
```

F reverses direction:

```text
compress
→ delete
→ attack the common architecture
→ freeze only what survives
→ classify unresolved interfaces
→ compare with production
→ admit the next residual
```

The standard for closure is not a maximally expressive formalism. It is the smallest grammar that prevents destructive collapse while remaining honest about what is not solved.

## 2. `Possible` is deleted as an untyped root predicate

A–E repeatedly showed that `possible` can mean:

```text
logically consistent
metaphysically possible? [unresolved]
nomologically admissible
reachable from actuality
reachable under an action set
strategically enforceable
resource-feasible
accessible through an interface
institutionally permitted
epistemically open
positive-probability / in measure support
```

There is no universal scalar predicate preserving these distinctions.

### Reconstruction

```text
Possible_τ(φ | Γ)
≈ truth of an existential/modal operator
  over a typed alternative/evaluation structure τ
  under dependence/background Γ.
```

### Disposition

```text
Possible root primitive: REJECTED
Typed possibility claim: RETAINED
```

---

## 3. `Necessary` is deleted as an untyped root predicate

The same reasoning applies to necessity.

```text
Necessary_τ(φ | Γ)
≈ φ satisfies the relevant universal/invariance operator
  over the τ-typed alternative structure.
```

Probability one does not provide necessity by itself; institutional obligation is not physical necessity; logical necessity is not nomological necessity.

### Disposition

```text
Necessary root primitive: REJECTED
Typed necessity/invariance claim: RETAINED
```

## 21. Falsifier T1 — Is TARA merely a disguised possible-world metaphysics?

No.

Its alternative domain can be:

```text
states
histories
trajectories
program runs
policies
strategy outcomes
institutional acts/statuses
model descriptions
measurement outcomes
```

The grammar does not require alternatives to be ontically concrete `possible worlds`.

### Survives if and only if

```text
AlternativeDomain is treated as query/model semantics,
not as ontology by default.
```

This restriction is frozen.

---

## 22. Falsifier T2 — Does shared accessibility mathematics collapse physical, epistemic and deontic modalities?

No, provided relation types and truth roles remain explicit.

The same relational form can encode:

```text
physical transition
program execution
evidence compatibility
institutional evaluation
```

without asserting identical truthmakers.

### Result

```text
SharedForm != SharedOntology
```

remains mandatory.

TARA survives.

---

## 23. Falsifier T3 — Is TARA too broad to be informative?

This is the strongest attack.

Once TARA allows:

```text
Relation
Generator
Evaluator
Operator
Measure
```

nearly any structured query can be encoded.

If TARA claimed:

> Reality fundamentally consists of these things,

it would be almost vacuous.

### Repair

TARA is therefore **demoted** from candidate ontology to a stricter role:

# Typed Modal Claim Grammar (TMCG)

Its purpose is only to force modal claims to expose:

```text
WHAT alternative/contrast domain?
WHAT modal/truth type?
WHAT relation/generator/evaluator?
WHAT operator/quantifier/measure?
WHAT background/dependence?
WHAT anchor, if relative?
WHAT model/evidence/interpretation provenance?
```

### Result

```text
TARA as Reality ontology: REJECTED
TARA/TMCG as modal claim grammar: SURVIVES & FREEZES
```

The name TARA can remain as the research lineage; the frozen content is the grammar, not an ontological architecture claim.

---

## 24. Falsifier T4 — Can dispositional/powers theories be represented without reducing powers to possible worlds?

Yes at the claim-grammar level.

A powers theory can provide the Reality-facing grounding from which modal manifestations/counterfactuals are modeled. TMCG need only represent the resulting modal claim and its theory provenance.

It does not say:

```text
Power = set of alternatives.
```

### Result

Powers/disposition rivals remain open; grammar survives.

## 25. Falsifier T5 — Does nomological possibility require local transitions?

No.

C explicitly admits global, all-at-once, variational, time-symmetric or constraint-style law candidates.

TMCG therefore allows an admissibility/evaluator over whole histories without a path generator.

### Result

```text
Modal grammar does not privilege state-machine dynamics.
```

Survives.

Yes, only if constitution remains upstream/distinct.

```text
Constitutive rule/status relation
→ institutional act/status
→ deontic modal evaluation/projection
```

The grammar evaluates permission/obligation over constituted statuses; it does not replace constitution.

### Result

```text

```

Survives.

## 27. Falsifier T7 — Can probability fit without equating measure with possibility?

Yes after E's refinement:

```text
support/admissibility
!= measure/weight
!= interpretation/truth role.
```

TMCG therefore treats measure as an optional operator layer, not the modal domain itself.

Survives.

## 28. Falsifier T8 — Can epistemic structural revision fit a fixed alternative domain?

Not inside one fixed model.

This is a real limitation.

The grammar must allow:

```text
AlternativeDomain_t
→ evidence/surprise
→ domain/model revision
→ AlternativeDomain_{t+1}
```

including new variables/actions/categories.

### Result

TMCG survives only as a **revision-capable meta-grammar**.

A fixed TMCG instance does not claim completeness.

### Frozen anti-law

```text
CurrentAlternativeDomain != CompleteRealityModalDomain
```

## 29. Falsifier T9 — Can TMCG distinguish model modality from Reality modality?

Yes, if every positive objective modal claim carries model/theory provenance or Reality-facing evidence position.

```text

```

must not silently become:

```text
Reality-impossible φ.
```

### Result

```text
ModelModalProjection != RealityModalTruth
```

is frozen.

## 30. Falsifier T10 — Does every modal claim need an explicit enumerable alternative set?

No.

The domain may be:

- implicit;
- symbolically defined;
- continuous;
- generated on demand;
- characterized by constraints;
- unknown/incomplete.

### Repair

`AlternativeDomain` in the grammar means a **declared contrast/admissibility universe or generator specification**, not necessarily a materialized set.

Survives.

---

## 31. Falsifier T11 — Does every modal claim need an Anchor?

No.

Examples:

```text
logical theorem necessity
some global nomological claims
```

may not use a distinguished current anchor.

But reachability, current capability and epistemic modality do.

### Result

```text
Anchor is optional and type-dependent.
```

Survives.

---

## 32. Falsifier T12 — Can TMCG itself explain why one relation is true?

No.

And this is intentional.

It can express:

```text
NomologicallyAdmissible_Θ(h)
```

but cannot tell us why Θ is genuinely lawlike.

It can express:

```text
do(X=x)
```

but cannot establish why model invariances track Reality causality.

It can express:

```text
Chance(E)=p
```

under a rival interpretation, but cannot settle the chance metaphysics.

### Conclusion

TMCG is a **semantic discipline/interface**, not a full theory of modal truthmakers.

This is its correct frozen scope.

# PART III — Frozen WDF1 modal foundation

## 33. WDF1 Modal Foundation v1

The positive frozen core is intentionally thin.

### M1 — Typed Modal Claim

Every nontrivial modal claim should be interpreted relative to a typed modal role and its dependence structure rather than as unqualified `possible/necessary/can`.

```text
ModalClaim_τ(φ | Γ)
```

---

### M2 — Alternative / Contrast Specification

A modal claim requires a declared or inferable alternative/contrast domain, admissibility condition or generation scheme appropriate to τ.

```text
Alt_τ / Generator_τ / Admissibility_τ
```

This is claim semantics, not a possible-world ontology commitment.

---

### M3 — Typed Relation / Generator / Evaluator

The relation that structures alternatives must preserve truth role:

```text
physical transition
nomological admissibility
program execution
Actor strategy
resource feasibility
interface coupling
epistemic compatibility
constitutive/deontic evaluation
```

are not one relation.

---

### M4 — Typed Operator

Modal force depends on the operator:

```text
∃ alternative
∀ alternatives
∃ path
∃ policy
∃ policy ∀ disturbance
∃ strategy ∀ opponents
safety/invariance
probability measure/threshold
deontic status evaluation
```

---

### M5 — Explicit Dependence / Background

Modal claims inherit relevant coordinates:

```text
law/theory
actual state/history
boundary/coupling
environment
horizon
Actor/system boundary
action/policy class
observation structure
resources/capacity
institution/rules
model/evidence
event space/measure
regime/tolerance
```

No universal list is mandatory, but hidden material dependence is a defect.

---

### M6 — Support / Weight / Interpretation Separation

For probabilistic modal claims:

```text
Alternative/modal support
!= Measure/weight
!= Interpretation/truth role.
```

---

### M7 — Reality / Model Modal Firewall

```text
Model-admitted
Model-impossible
Model-probable
Agent-epistemically-open
```

are not automatically Reality modal truths.

A model's alternative domain and measure remain revisable.

---

### M8 — Derived Actionability

Current actionability/capability is a derived relation over:

```text
objective/dynamic possibility
+ Actor observation/action coupling
+ policy/strategy relation
+ resources/capacity
+ access/coupling
+ authority/admission
+ horizon/success criterion
+ current evidence.
```

No global capability essence is required.

---

### M9 — Intervention Distinction

```text
ordinary action occurrence
!= formal causal intervention/model surgery.
```

Intervention is a typed alternative generator relative to a causal model/query, not a generic synonym for action.

---

### M10 — Structural Revision

Modal models must admit revision of:

```text
alternative domain
variables
relations
operators
model class
```

when evidence/surprise indicates structural inadequacy.

---

## 34. Frozen compressed grammar

The smallest useful WDF1 grammar is:

```text
MODAL CLAIM
│
├─ Target / proposition / outcome φ
├─ Modal truth role τ
├─ Alternative / contrast specification Ωτ or Gτ
├─ Typed relation / generator / evaluator Rτ
├─ Typed operator Qτ
├─ Dependence / background Γ
├─ Anchor a                     [when relative]
├─ Measure / weight μ           [when probabilistic]
├─ Measure interpretation ρ     [when semantically needed]
└─ Model/evidence provenance     [for epistemic/operational claims]
```

This is **not** asserted to be a list of ontological furniture.

It is the minimum question grammar that survived A–F.
