# 2. First canonical firewall — three different structural layers

F establishes:

```text
TargetPropertyStructure
!= EvaluationValueStructure
!= RepresentationEncoding
```

Canonical shorthand:

```text
PS = Target Property Structure
VS = Evaluation / Value Structure
RE = Representation / Encoding
```

## PS

The relations, distinctions, operations, composition rules, topology, order, or other structure that are actually warranted for the target property under the declared criterion/CVE.

## VS

The structure of the values used by an evaluation to state what has been attributed to the target.

## RE

The concrete symbols, numerals, coordinate tuples, labels, bit patterns, textual forms, or display formats used to encode those values.

Examples:

```text
blood type:
PS may support equivalence/distinct category structure
VS may be {A,B,AB,O}
RE may be strings or integers 1..4

hardness:
PS may support order
VS may be ordered classes/levels
RE may be 1..10 or symbolic labels

vector profile:
PS may support multidimensional variation
VS may be a vector space/manifold/profile space
RE may be coordinate tuples
```

Thus:

```text
RE structure cannot be read back into PS by default.
```

# 3. Numericity falsification

Arbitrary identifiers supply the minimal case:

```text
object A -> 101
object B -> 205
object C -> 330
```

The output is numerical.

But unless arithmetic/order/difference/ratio relations among those numbers correspond to target-relevant structure:

```text
101 < 205
205 - 101
330 / 101
```

carry no target semantics.

Therefore:

```text
NumericEncoding
!= Quantification
```

and:

```text
NumericalOperationsAvailableInRE
!= SemanticallyLicensedOperationsInVS/PS
```



Therefore:

```text

NOIR != exhaustive EvaluationStructure ontology
```

Independent methodological work also shows that the received ordinal/interval distinction can be too coarse for actual scientific scales and associated inferences.

# 30. Representation transformation vs evaluation revision

Changes RE while preserving the same VS semantics.


## Evaluation revision

Changes the property-value/evaluation semantics themselves.

Examples:


```text

!= EvaluationStructureRevision
```
