
## 4.2 Universals / tropes / modes / bundle / one-category rivals

Rival ontologies disagree over whether properties are:

```text
universals

sets/classes
ways objects are
structural roles
reducible descriptions
or not independent entities at all.
```

Current WDF has no adjudication.

Residual: **strong**.

## 4.3 Fact / state-of-affairs / truthmaker traditions

These ask whether true claims correspond to or are made true by:

```text
facts
states of affairs
events
objects + properties
truthmaking relations
or Reality globally without dedicated truthmaker entities.
```

WDF0's Reality/representation firewall does not settle truthmaking.

Residual: **strong**.

## 4.4 Grounding / ontological dependence / fundamentality

This is distinct from:

```text
causation
constitution
logical entailment
mereological parthood
explanation
```

Current WDF uses constitution/realization and dependence language but has not established a grounding architecture.

Residual: **strong**.

## 4.5 Process / event metaphysics

Object-centric, event-centric and process-centric views disagree about whether persistence-bearing things or happenings/processes are ontologically primary.

WDF0 includes Transformation/History and warns against taking Object as a universal root, but no event/process foundation exists.

Residual: **moderate-strong**.



Current WDF does not distinguish taxonomy from ontology strongly enough.

## 4.7 Quantity / magnitude / measurement theory

Physics and engineering require distinctions among:

```text
quantity
magnitude
number
unit
dimension
scale
measurement procedure
```

Treating all quantities as bare numeric fields would collapse Reality, representation and measurement.

Current WDF0/measurement residual does not yet solve this.

Residual: **strong**.

## 4.8 Negative ontology / absence / holes / privations


The previous closeout mentioned omission under causation but not absence/privation as a general categorial problem.

Residual: **moderate-strong**.

## 4.9 Philosophy of mathematics / mathematical structuralism

Open questions include:

```text
Do mathematical objects/structures belong to Reality?
```

Current WDF strongly warns `SharedForm != SharedOntology`, but does not yet supply the abstract/realization architecture.


Classification: **major World-core physical residual**.

## 5.3 Gauge theory / symmetry / redundancy

A crucial omitted problem is:

```text
Different mathematical states/descriptions may represent the same physical Reality.
```

But rival interpretations disagree about whether gauge structure is merely descriptive redundancy or reflects intrinsic geometry.

This creates a general question:

```text
DescriptionDifference ?= RealityDifference
```

that is not exhausted by Representation != Reality.

Classification: **structurally homeless cross-cutting World residual**.

## 5.4 Duality / theoretical equivalence

Dual physical theories can be formally dual while disagreeing under some interpretations; formal equivalence therefore does not automatically establish ontological identity.

This attacks any naive equivalence criterion based only on syntax/model isomorphism.

Classification: **strong cross-cutting residual**.

## 5.5 Effective field theory / renormalization / universality

Pressure:

```text
scale-relative descriptions can be objectively valid
different micro-details can flow to the same macro behavior
formal RG variants have different explanatory roles
```

WDF0 scale firewalls remain good, but no general scale/effective-reality foundation exists.

Classification: **genuine later World-core residual**.

## 5.6 Thermodynamics / non-equilibrium / active matter

Open systems and reaction-diffusion systems show that persistent organized structures can require ongoing dissipation and may not be reconstructible as static objects.

Classification: **genuine later World-core residual**, interacting with process, system, life and emergence.

# 9. Agent-era search: what is truly new versus amplified old structure?

## 9.1 Machine-mediated observation

New scale and prevalence, but largely composes:

```text
measurement + provenance + representation + agent action
```

World ownership: cross-cutting.

## 9.2 Machine-mediated action / delegation

Operational semantics strongly owned by Runtime/Harness/Host.

World ownership: generic action/causal/authority interface only.

## 9.3 Autonomous agent populations

Recent long-horizon multi-agent experiments show governance topology, behavioral drift and cross-agent influence becoming measurable system properties over weeks rather than isolated task episodes.

This is real Agent-era amplification.

But generic population/institution/dynamics theory exists pre-Agent.

Classification: **new regime, not yet proven new root category**.

## 9.4 Programmable / executable institutions

Rules can become code that directly changes permissible transitions and institutional status.

This creates unusual rule-text/rule-code/implementation/version interactions.

But it composes:

```text
institutional constitution + software realization + authority + execution
```

Classification: **cross-cutting; Agent-era novel regime, not immediate root**.

## 9.5 Model-mediated performativity

Predictive models can change the data-generating process through deployment, creating decision-dependent distributions and equilibria.

This is not merely epistemic error:

```text
Model/Prediction
→ Action/Response
→ changed Reality distribution/state
→ new evidence
→ new model
```

Harness HaF28 already owns a rich reflexivity/performativity foundation for Agent-support systems.

World still needs the generic Reality/model feedback interface, but ownership is cross-cutting.

## 9.6 Synthetic-data feedback

Recursive training on model outputs can alter future model distributions; outcomes depend materially on whether synthetic outputs replace or accumulate with real data.

This gives a concrete Agent-era case where:

```text
Representation artifacts become future causal training-environment facts.
```

Important falsifier, but reducible to performativity + provenance + dynamics + learning at World level.

## 9.7 Copy / fork / merge / rollback identity

Operationally important, but Harness/Runtime already own version-relative Agent identity and recovery semantics.

World-level residue is generic persistence/identity criteria.

## 9.8 Hybrid physical-digital entities

Examples include digital twins, robots with remote control planes, financial/legal digital assets and machine-governed physical infrastructure.

These challenge a clean physical/digital object partition.

Likely reconstruction:

```text
one criterion-relative entity/status
may have multiple realizations, representations and authority surfaces.
```

This pressures categorial/identity/realization foundations rather than proving a new Agent-only ontology.

## 9.9 Protocol/schema-mediated constitution

Machine-readable schemas increasingly determine which actions/statuses exist operationally.

Yet:

```text
Schema != SemanticContract != InstitutionalRule != RealityStatus
```

Runtime/Harness own local semantics; World owns only generic constitution/reference questions.
