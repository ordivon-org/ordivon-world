# WDF1-1E — Objective Modality / Epistemic Openness / Probability / Chance Separation

Status: complete for WDF1-1E. No interpretation of probability or metaphysics of chance is selected. TARA survives and is refined by separating **support/admissibility**, **measure/kernel**, and **interpretation/truth role**. Probability is not retained as one World primitive; a probability value is a formal/model quantity whose semantic role must be typed. `ObjectiveChance` remains an unresolved Reality-facing candidate, not a synonym for probability measure, frequency, credence, uncertainty or propensity. Exact next sub-round: **WDF1-1F — Modal Architecture Reconstruction / Falsification / WDF1-1 Closeout**.

## 0. Question

WDF1-1D reconstructed probabilistic control claims such as:

```text
∃π_A : μ(success | π_A) ≥ p
```

but intentionally left `μ` uninterpreted.

WDF1-1E asks:

> What does a probability number mean? Is it an Agent's degree of belief, a statistical model weight, a long-run frequency, a stochastic law, an objective single-case chance, a propensity/disposition, or something else?

It also attacks two dangerous modal collapses:

```text
P(E)=0 => E is impossible
P(E)=1 => E is necessary
```

and the equally dangerous epistemic collapse:

```text
uncertainty => Reality is stochastic.
```

## 1. First firewall — probability calculus vs probability interpretation

Kolmogorov-style probability theory provides a formal structure:

```text
(Ω, F, μ)
```

where:

```text
Ω = sample/alternative domain
F = event algebra / sigma-algebra
μ = normalized measure satisfying probability axioms
```

The formal axioms do **not by themselves** tell us what `μ` is in Reality or epistemology.

The same formal measure machinery can be used for:

- subjective credence;
- a statistical sampling model;
- a stochastic transition kernel;
- an objective-chance theory;
- a Bayesian posterior/predictive distribution;
- a frequency-based model;
- a propensity-inspired model.

### Hard anti-law

```text
ProbabilityMeasure != ProbabilityInterpretation
```

and:

```text
SameFormalμ != SameTruthRole
```

This is the most important starting point for E.

## 7. Frequency role

For repeated trials, empirical relative frequency is:

```text
f_n(E) = count(E in first n trials)/n
```

This is an actual statistic of a realized sequence.

It is not numerically identical by definition to the probability parameter of a model.

Large-number theorems connect model probability and frequency under explicit assumptions, e.g. independent/repeated trial conditions, by showing concentration/convergence properties.

### Hard anti-law

```text
ObservedFrequency != ProbabilityParameter by definition
```

and:

```text
FiniteFrequency != ObjectiveChance
```
