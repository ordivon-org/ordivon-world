## 3. Why automatic WDF6 is unsafe

Current World research history uses `WDF*` identifiers as strong historical route identities. In particular WDF4 and WDF5 were selected from whole-Reality tournaments and then used as owner-line identifiers throughout their research chains.

That creates ambiguity over whether a WDF integer means:

```text
historical admission order
canonical registry index
priority
ontological level
research roadmap order
```

No independent global registry specification currently resolves those meanings.

Therefore assigning WDF6 now would create semantics not earned by research.

```text

Foundation = TSAF0 Temporal Structure
```

## 5. Future registry requirements

A proper global World registry should explicitly guarantee:

```text
RegistryNumber != Priority
RegistryNumber != Rootness
RegistryNumber != ResearchOrder
RegistryNumber != Roadmap
RegistryNumber != DependencyLevel
```

It should record independently:

```text

foundation identity
status/freeze state
owner boundaries
dependency/consumption edges
reopen conditions
research-history links
registry/index metadata
```

Only after such a registry architecture exists should TSAF0 receive a global mapping.
