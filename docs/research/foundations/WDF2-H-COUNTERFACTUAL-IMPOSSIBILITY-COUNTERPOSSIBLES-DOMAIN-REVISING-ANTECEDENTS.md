# 1. Objective

WDF2-G established a completion-based view of cross-world coherence.

But that architecture assumed that each branch can at least be interpreted in some declared domain/model extension.

WDF2-H asks what happens when the antecedent itself is impossible under the current framework.

The central question is not merely:

```text
Is antecedent A impossible?
```

but:

> **Impossible relative to what, and what kind of structural repair or alternative-domain extension—if any—makes the counterfactual evaluable without collapsing all impossible antecedents into vacuity or arbitrary fantasy?**

The round compares:

```text
vacuism / strict possible-world semantics
impossible-world semantics
premise/background revision
law-revision / small-miracle semantics
backtracking / initial-condition revision
constitutive-rule revision
semantic/conventional revision
model revision
alternative-domain extension
typed plural routing
```

No family is preselected as universal.

---

# 2. First decisive result — impossibility is indexed

The untyped predicate:

```text
Impossible(A)
```

is insufficient.

At minimum:

```text
Impossible(A | Logic L)
Impossible(A | MathematicalTheory T)
Impossible(A | Laws N)
Impossible(A | Laws N + ActualPast H)
Impossible(A | ConstitutiveRules K)
Impossible(A | Model M)
Impossible(A | SemanticScheme S)
Impossible(A | CandidateMetaphysicalConstraints E)
```

### Earned firewall H-IDX-1

```text
Impossible != OneUntypedModalStatus
```

The repair operation depends on which index generates impossibility.

---

# 3. Impossibility truth role must be explicit

An antecedent can be:

```text
proved inconsistent in one formal theory
excluded by a current scientific model
excluded by current law hypothesis
constitutively invalid under current institutional rules
unrepresentable by the current variable vocabulary
believed metaphysically impossible
```

These are not the same truth role.

### Earned firewall H-TRUTH-1

```text
ModelUnsatisfiable != RealityImpossible
```

and:

```text
CurrentTheoryImpossible != MetaphysicallyImpossible
```

unless an additional grounding argument is supplied.

# PART I — IMPOSSIBILITY TAXONOMY

# 4. Logical inconsistency under fixed logic

Example:

```text
P and not-P
```

under classical logic and one exact proposition/time/index.

The antecedent has no classical model.

This is **fixed-logic logical impossibility**.

---

# 5. Mathematical/theory-relative impossibility

Example:

```text
square the circle with straightedge and compass
```

under Euclidean geometry plus the standard construction constraints.

This is not merely `P and not-P` syntactically.

It is impossible relative to a mathematical theory and operation specification.

---

# 6. Nomological impossibility

Example:

```text
system trajectory violates actual/assumed law N
```

while the described state may remain logically coherent.

This is **law-relative impossibility**.

---

# 7. Historical inaccessibility

In a deterministic world, given:

```text
actual past H
+
laws N
```

many ordinary counterfactual antecedents at a later time are inaccessible.

But they need not violate N in every history.

### Earned firewall H-HIST-1

```text
HistoricallyInaccessibleGivenActualPast
!= NomologicallyImpossibleSimpliciter
```

This distinction blocks classifying every deterministic counterfactual as a counterpossible.

---

# 8. Constitutive impossibility

Institutional example:

```text
Under rule K,
status S requires conditions C.
Antecedent says S holds while C is explicitly absent and K is preserved.
```

This is not primarily physical impossibility.

It is **constitutive/rule-relative impossibility**.

---

# 9. Semantic/conventional impossibility

Example:

```text
Under semantic scheme S,
term T is defined such that predicate pair A/B is incompatible.
```

An antecedent can either:

```text
violate S while preserving meanings
```

or:

```text
revise S itself.
```

These must be distinguished.

---

# 10. Model impossibility

A query can be impossible only because current model M:

```text
has no variable for target
has domain excluding requested value
has no solution under intervention
cannot represent mechanism change
```

### Earned firewall H-MODEL-1

```text
ImpossibleInCurrentModel
!= ImpossibleInReality
```

This usually triggers model revision before modal metaphysics.

---

# 11. Candidate metaphysical impossibility

Claims concerning:

```text
essence
identity across origins
category membership
fundamental metaphysical dependence
```

may be treated by some theories as metaphysically necessary/impossible.

WDF2-H does not settle these metaphysical disputes.

It records:


as a distinct provenance-bearing status.

# 12. Unknown impossibility source

```text
ImpossibilitySourceUnderdetermined
```

# PART II — VACUISM

# 13. Standard vacuity pressure

In a simple Lewis/Stalnaker-style possible-world semantics:

```text
A □→ B
```

is evaluated using closest possible A-worlds.

If there are no possible A-worlds, then no A-world falsifies B.

The conditional is therefore vacuously true under the orthodox treatment.

---

# 14. Vacuism is coherent, not a category error

Timothy Williamson explicitly defends the view that counterpossibles with impossible antecedents are true, arguing that non-vacuist intuitions can arise from a fallible suppositional heuristic.

WDF2-H therefore rejects caricature:

```text
Vacuism = obviously incoherent
```

It is a coherent semantics with a strong consequence.

---

# 15. The cost of vacuism

If A has no possible worlds, then:

```text
A □→ B
A □→ not-B
```

can both be vacuously true.

Thus the semantics cannot use ordinary possible-world extension alone to distinguish consequents for that antecedent.

### Earned firewall H-VAC-1

```text
VacuousTruth != InformativeDependence
```

---

# 16. Vacuism can be query-appropriate

Some uses may genuinely ask only:

```text
Does every possible A-world satisfy B?
```

If there are none, vacuity can be mathematically correct for that formal query.

WDF2-H therefore does not globally reject vacuity.

---

# 17. Vacuism cannot serve all scientific/explanatory roles by stipulation

Scientific practice has been argued to distinguish non-vacuously among impossible antecedents, including cases where one counterpossible is treated as useful/true and another with the same impossible antecedent as false/irrelevant.

Therefore a World foundation cannot assume that every query role wants the vacuous universal reading.

---

# PART III — NON-VACUISM AND IMPOSSIBLE WORLDS

# 18. Impossible-world extension

One non-vacuist strategy adds alternatives in which impossible antecedents hold.

Then:

```text
A □→ B
```

can depend on which impossible A-alternatives are selected.

---

# 19. Impossible worlds solve one problem but expose another

Adding impossible worlds provides antecedent-satisfying alternatives.

It does **not** by itself determine:

```text
which impossible worlds are admissible
which logic they obey
which contradictions propagate
how similarity is measured
which facts/laws/meanings are preserved
```

### Earned firewall H-IW-1

```text
ImpossibleWorldExistence != CounterpossibleSelectionSolution
```

---

# 20. Similarity problem becomes hyperintensional

If two antecedents are impossible, their extension over ordinary possible worlds is equally empty.

Yet non-vacuist reasoning often treats their contents differently.

Impossible worlds can encode finer distinctions, but then a granularity/relevance problem appears:

```text
How fine-grained should impossible alternatives be?
Which differences matter?
```

This becomes a major residual for WDF2-I.

---

# 21. No “anything goes” license

Impossible alternatives must not be treated as unconstrained fantasy.

A useful impossible-world/domain-extension semantics still requires:

```text
antecedent realization
protected background
relevance constraints
local inferential rules
identity/correspondence
failure/explosion policy
```

---

# PART IV — LOGICAL IMPOSSIBILITY

# 22. Fixed-logic contradiction

Antecedent:

```text
P and not-P
```

under classical logic.

If imported as ordinary premises into classical consequence, explosion threatens:

```text
P, not-P ⊢ Q
```

for arbitrary Q.

Then every consequent can appear supported.

---

# 23. Explosion is not the only conceivable counterpossible semantics

Non-vacuist frameworks can instead use:

```text
relevance restrictions
paraconsistent evaluation
impossible-world local truth assignments
premise revision
```

WDF2-H does not choose one universally.

### Earned firewall H-EXP-1

```text
ContradictoryAntecedent
!= LicenseForArbitraryConsequent by foundation default
```

---

# 24. Object-level contradiction vs logic revision

Compare:

```text
A. If P and not-P were both true under classical logic...
```

with:

```text
B. If paraconsistent logic rather than classical logic governed consequence...
```

A violates a fixed inferential framework.

B revises the inferential framework.

### Earned firewall H-LOGIC-1

```text
ContradictionWithinLogicL
!= CounterfactualAboutReplacingLogicL
```

---

# 25. Counterlogicals are framework-sensitive

A counterfactual such as:

```text
If classical explosion were invalid, then ...
```

cannot be evaluated by first assuming classical explosion globally without begging the question.

The logic used to reason *about* the antecedent must be separated from the logic stipulated *inside* the antecedent domain.

---

# 26. Meta-logic vs object-logic

WDF2-H therefore requires:

```text
MetaReasoningLogic
!= CounterfactualObjectLogic
```

when the antecedent revises inferential rules.

This is one form of domain revision.

# 27. Theory-relative mathematical counterpossible

```text
If Hobbes had squared the circle with straightedge and compass...
```

The impossibility depends on:

```text

```

---

# 28. Different repair routes answer different questions

One could imagine:

```text
change Euclidean axioms
change allowed tools
change meaning of “square the circle”
allow inconsistent mathematics
represent an impossible construction directly
```

These are not semantically equivalent repairs.

---

# 29. Tool-change is not theorem falsification

If a construction becomes possible because arbitrary mechanical devices are allowed, then:

```text
“straightedge-and-compass impossibility was false”
```

has not been established.

The intervention specification changed.

### Earned firewall H-MATH-1

```text
OperationSetRevision != MathematicalTheoremFailure
```

---

# 30. Mathematical counterpossible can be explanatory without physical executability

Scientific/mathematical reasoning can ask what would follow under a false theorem/idealization.

Actionability remains irrelevant unless query role demands it.

# PART VI — NOMOLOGICAL IMPOSSIBILITY / COUNTERNOMICS

# 31. Law violation is not logical contradiction

Antecedent:

```text
object accelerates contrary to actual law N
```

may remain logically describable.

The issue is which law structure is preserved.

---

# 32. Small-miracle style

A Lewis-style counterfactual may permit a localized departure from actual law to realize the antecedent while preserving broad actual-law similarity elsewhere.

In SCM language, forward intervention commonly modifies a local structural equation while exogenous background remains shared.

This is a **local law/mechanism surgery** family.

---

# 33. Backtracking style

Alternatively one may preserve causal laws and modify upstream/exogenous conditions so the antecedent arises naturally.

Thus:

```text
LawViolationRoute
!= BacktrackingInitialConditionRoute
```

WDF2-A/D already established this for ordinary cases; H extends it to impossibility classification.

---

# 34. True counternomic

If antecedent itself requires:

```text
law N to be false/replaced
```

then merely changing initial conditions cannot realize it.

One needs:

```text
LawRevision
```

or an alternative-domain representation.

---

# 35. Law-revision requires a preservation question

If N is replaced by N', what remains fixed?

Candidates:

```text
same objects
same initial macrostate
same mathematical state space
same symmetries
same constants except c
same measurement conventions
```

No universal answer exists.

### Earned firewall H-LAW-1

```text
ChangeLaw(N->N')
!= PreserveAllOtherActualFacts
```

Many actual facts depended on N.

---

# 36. Laws as counterfactual invariants remain philosophically contested

Research on laws and counterfactual invariance shows that even the relation between lawhood and counterfactual preservation is itself a substantive philosophical issue.

Therefore WDF2-H does not define law simply as “whatever is held fixed in counterfactuals.”

# PART VII — HISTORICAL IMPOSSIBILITY

# 37. Deterministic actual history case

Given exact past H and deterministic laws N:

```text
At t, X=x'
```

may be impossible relative to `(H,N)` even though there are N-obeying histories where X=x'.

---

# 38. Counterfactual role distinction

For consequence/planning:

```text
local intervention at t
```

may be intended.

For diagnostic/backtracking:

```text
alter earlier H
```

may be intended.

Thus historical inaccessibility is a generator-selection issue, not necessarily counterpossible semantics.

---

# 39. Special-science grain

A macro-level antecedent can be accessible in a coarse special-science model even if exact microphysical actual past plus deterministic laws fix a different microtrajectory.

### Earned firewall H-GRAIN-1

```text
MicroHistoricalInaccessibility
!= MacroCounterfactualMeaninglessness
```

```text

```

can be constitutively inconsistent.

---

# 41. Rule-revision counterfactual

Compare:

```text

```

This is not the same impossible antecedent.

It is a **rule-revising antecedent**.

### Earned firewall H-RULE-1

```text
ViolationUnderFixedRule
!= RevisionOfRule
```

---

# 42. Physical token vs status

If an old credential token is imported after K changes, the physical token may persist while the institutional status changes.

```text
PhysicalToken != InstitutionalStatus
```

# 43. Constitutive revision can change proposition content

After K changes, statement:

```text

```

may express a different institutional criterion.

Thus domain revision can alter the very proposition being compared.

This directly creates hyperintensional pressure.

# 45. Mention-use firewall


### Earned firewall H-SEM-1


# 46. Definition-violation vs definition-revision

Compare:

```text
A. If a bachelor were married, while “bachelor” retained its current definition...
```

with:

```text
B. If “bachelor” meant married adult...
```

A is fixed-definition contradiction.

B is semantic revision.

No single impossible-world repair should silently conflate them.

# PART XXI — RIVAL ARCHITECTURES

# 88. Vacuist architecture

Strengths:

```text
simple
preserves orthodox possible-world semantics
clear quantificational behavior
```

Weakness:

```text
no internal discrimination among impossible antecedent cases at truth-value level
```

unless pragmatic/heuristic explanations carry the work.

---

# 89. Impossible-world architecture

Strengths:

```text
non-vacuous evaluation
hyperintensional discrimination potential
```

Weaknesses:

```text
world granularity
relevance/similarity
logic at impossible worlds
constraint propagation
```

remain nontrivial.

---

# 90. Premise/background revision architecture

Strengths:

```text
represents reasoning from inconsistent/false supposition by selectively revising background
```

Weakness:

```text
which premises survive/relevance priorities require grounding
```

---

# 91. Law-revision architecture

Strength:

```text
fits counternomic/scientific hypothetical roles
```

Weakness:

```text
not suited to logical or constitutive impossibility without further domain typing
```

---

# 92. Rule/convention-revision architecture

Strength:

```text
fits institutional/semantic counterconventionals
```

Weakness:

```text
can change proposition identity and correspondence conditions
```

---

# 93. Model-revision architecture

Strength:

```text
prevents representational limitation from masquerading as Reality impossibility
```

Weakness:

```text
model extension can silently change query content if correspondence not audited
```

---

# 94. Typed plural architecture

Surviving meta-architecture:

```text
classify impossibility source
identify query role
select admissible repair/extension families
preserve provenance
```

> **WDF2-H finds that impossibility is not one primitive modal status but an indexed claim relative to logic, mathematical theory, laws, actual history, constitutive rules, model vocabulary, semantic convention or contested metaphysical constraints. This typing changes counterfactual evaluation fundamentally. Historical inaccessibility under deterministic laws is not the same as nomological impossibility; institutional invalidity is not physical impossibility; model unsatisfiability is not Reality impossibility; lack of authorization is not lack of capability. Non-vacuist impossible-world approaches restore antecedent-realizing alternatives but do not by themselves solve relevance, similarity, inferential closure or preservation. The strongest surviving architecture is therefore typed and plural: first classify the impossibility source, then distinguish violating a fixed framework from counterfactually revising that framework, then select admissible repair/domain-extension families, migrate preservation and correspondence, and retain robust/plural results across surviving extensions. Logical, law, rule, semantic and model revisions are different operations.
