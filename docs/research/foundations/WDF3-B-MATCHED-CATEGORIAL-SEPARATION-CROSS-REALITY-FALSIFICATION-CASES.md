# 3. Characterization versus classification/kind

## Pair P1 — Same extension, different characterization candidate

Suppose two predicates happen to apply to exactly the same current objects.

For example, in a bounded current domain:

```text
P(x) = x has property profile A
Q(x) = x belongs to kind K
```

may be extensionally coextensive.

Deleting characterization into class extension would imply:

```text
SameCurrentExtension(P,Q)
→ SameRealityCharacterization
```

This does not survive counterfactual substitution.

A future object may instantiate the characterization without belonging to the kind, or belong to the kind while lacking one currently correlated characteristic.

### Result

```text
ExtensionEquality != CharacterizationIdentity
```

Characterization cannot be reduced to current class membership.

---

## Pair P2 — Same kind, different properties

Biological species provide a strong matched case.

Members of one species can differ in morphology, physiology, developmental history and local environment; historical/genealogical or homeostatic accounts of species need not make every shared property necessary for membership.

Hold fixed:

```text
lineage/species membership
```

vary:

```text
one phenotype/property
```

The organism can remain a member of the species.

Therefore:

```text
KindMembership != PossessionOfOneNecessaryProperty
```

---

## Pair P3 — Same property profile, different kind criterion

Two populations can converge on highly similar observable properties while differing in historical origin, causal mechanism or institutional constitution.

Examples:

```text
convergent biological forms
chemically distinct substances with similar macroscopic behavior
institutional roles with identical current permissions but different legal basis
software artifacts with identical current I/O but different semantic contracts
```

Therefore:

```text
PropertyProfileEquality != KindIdentity
```

### Verdict C/K

```text
Characterization → Classification reduction: FAILS
Classification → Characterization reduction: FAILS
Kind = property bundle universally: FAILS
```

But B also finds:

```text
Kind as one independent entity category is NOT established.
```

What survives is a distinct **classification/individuation-by-kind role** whose criterion may be:

```text

compositional

functional
institutional
specification-relative
or mixed.
```

# 11. Grounding / ontological dependence versus causation

## Pair G1 — Same causal history, different institutional grounding

Suppose the same physical token and causal production history exists in two institutional regimes.

In regime I1:

```text
token T + valid constitutive rule/history → valid certificate/status S
```

In regime I2:

```text
same physical token T and physical causal history
but no valid rule/status relation → no S
```

The physical causal chain can be held substantially fixed while institutional status differs.

Therefore:

```text
InstitutionalDetermination != PhysicalCausation
```

## Pair G2 — Same cause, different constitution

The same causal antecedent can create two artifacts whose institutional or compositional status depends on different constitutive relations.

Causal production does not determine whether a lump and statue, bytes and document, or execution and transaction-status are identical, constituted, or merely correlated.

## Pair G3 — Same constitution, different causal role

An object's material constitution may remain constant while its causal role changes with environment.

Therefore:

```text
Constitution != CausalRole
```

## Pair G4 — Realization without ordinary causation

A lower-level structure can realize a functional/abstract role synchronically. Asking what realizes the role is not ordinarily identical to asking what earlier event caused the role to exist.

Therefore:

```text
Realization != OrdinaryDiachronicCausation
```


Equivalence becomes `DifferenceRelevance / Invariance`.

# 37. Final compressed judgment

WDF3-B shows that WDF3-A was not merely vocabulary hygiene. Several candidate roles can actually be removed once matched cases are forced through the grammar: quantity is better treated as quantitative characterization; absence as a derived negative/contrast construction; occurrence as a temporal individuation profile; equivalence as a cross-cutting invariance/difference-relevance relation; identity as a criterion coordinate rather than one peer category.

But five distinctions still resist cross-regime deletion: how something is characterized, what kind it is, what obtains, what noncausally determines/grounds what, and how something realizes/constitutes/instantiates another structure or status. Their survival does not prove five fundamental ontological furniture types. It proves that a general World model cannot currently collapse their truth roles without losing distinctions across physics, biology, institutions, software and Agent-era systems.

The next rational move is therefore not to deepen one survivor. It is to put major rival categorial architectures against the same matched-case battery and ask which architecture can reconstruct the surviving roles with the smallest ontology and the fewest hidden imports.
