# WDF1-A — Nomology / Modality / Causality Current-Use & Hidden-Assumption Inventory

Status: complete for WDF1-A. No law, modal or causal theory is selected. WDF0 Meta-Foundation v1 remains frozen. The exact next residual-driven round admitted by WDF1-A is **WDF1-B — Matched Modal Separation Cases**; WDF1-B–G then carry the Modal Architecture program through falsification and closeout. Law and causation theory comparison remains open and must not be decided before the modal kinds are separated.

## 0. Why WDF1 begins here

WDF0 closed after discovering that Ordivon had already depended on a large family of words without a sufficiently deep World-level account:

```text
possible
impossible
necessary
reachable
feasible
accessible
authorized
constraint
law
regularity
disposition / power / capacity
cause
effect
mechanism
intervention
counterfactual
chance / probability / uncertainty
```

The danger is not simply vague terminology. These words currently sit underneath:

- Resource → Option → Capability reasoning;
- current path/actionability;
- institutional permission and authority;
- physical/environment constraints;
- Action → Effect → Outcome → Attribution separation;
- experimental intervention;
- causal transport;
- Agent planning and recovery;
- claims about what would happen under changed conditions.

WDF1-A therefore does not ask `which theory of causation is right?` first. It asks:

> What different questions has Ordivon already been using the same words to answer, which distinctions are already earned by engineering/research failures, and which rival theories would silently redefine those questions?

## 1. Method

WDF1-A uses five passes:

```text
A. Current-use inventory
B. Term separation
C. Rival law / modality models
D. Rival causation models
E. Dependency and circularity audit
```

The test is not elegance. For every concept, ask:

1. What is the target claim?
2. Is the claim about Reality, an Actor-relative relation, an institution-relative status, or epistemic/model state?
3. What alternatives are being considered?
4. What excludes alternatives?
5. What makes an alternative reachable or actionable from actuality?
6. What observation/intervention could distinguish rival claims?
7. Which theory terms are being smuggled into the definition of another term?

## 2. Current Ordivon inventory — Capability already imports causality and modality

Current canonical doctrine says:

```text
Capability = supported ability of a declared system boundary
             to cause or obtain a class of state transition
             under bounded conditions.
```

This definition is disciplined operationally but foundationally loaded.

It contains at least:

```text
supported        → epistemic/evidence relation
ability          → modality/disposition
system boundary  → WDF0 derived decomposition
cause            → causal relation
obtain           → potentially non-causal route to outcome
state transition → model-relative transition description
conditions       → constraint/background structure
```

Thus `Capability` is not merely downstream of modality/causality. It is a compact **bundle** of several unresolved WDF1 notions.

### Hidden assumption CA-1

`ability to cause or obtain` currently leaves two importantly different routes under one capability term:

```text
productive route:
Actor intervention causally produces transition

access/coordination route:
Actor obtains transition through an external owner, institution or existing process
```

For example, an Agent can `obtain` an external effect by invoking an authorized service whose internal mechanism is not owned by the Agent.

Therefore:

```text
CapabilityToCause != CapabilityToObtain
```

unless the query intentionally abstracts over the distinction.

## 3. Resource / Option doctrine already uses multiple modalities

The canonical Resource / Option / Capability doctrine currently says:

```text
ResourceFor
+ required current authority
+ required current access/materialization
+ semantic fit
+ binding constraints
→ ActionableResourceFor
```

and:

```text
Option = selectable feasible relation available to a decision-maker
         under current demand/context.
```

`Feasible(T)` further depends on:

```text
requirements
assignments
material compatibility
authority
quantity
time
semantic constraints
```

This is a strong practical doctrine, but WDF1-A finds that `feasible` is acting as an umbrella over heterogeneous exclusion relations.

### Hidden assumption RO-1 — one feasibility predicate hides several gates

A transition can be:

```text
physically possible but unauthorized
technically reachable but resource-infeasible
authorized but inaccessible through the current path
semantically admissible but capacity-infeasible
epistemically open while physically impossible
```

Therefore a single untyped `Feasible` cannot be treated as fundamental modality.

## 4. `Constraint` is already plural in current World usage

Current Resource doctrine explicitly lists constraints involving:

```text
material compatibility
authority
quantity
time
semantics
```

Capability doctrine activates institutional rules concerning:

```text
allocation/access
authority/admission
incentive/cost
enforcement/sanction
ownership/appropriation
coordination/information
recovery/exit
```

These do not all constrain in the same ontological way.

Compare:

```text
conservation law             — physical/nomological
wall geometry                 — physical boundary/realization
insufficient capital          — resource/quantity
API unreachable               — path/access
permission denied             — institutional/deontic
timeout before completion     — horizon/dynamical
model lacks evidence          — epistemic/action-decision constraint
```

### Hidden assumption C-1

`Constraint` currently means at least:

> any fact/relationship whose satisfaction or violation changes the admissible/reachable/actionable set for the query.

That is a useful meta-role, not yet one ontological kind.

Therefore:

```text
ConstraintRole != OneConstraintOntology
```

## 5. Current Ordivon already distinguishes Effect from Attribution — retain this firewall

Resource doctrine states:

```text
Action
!= Effect
!= Outcome
!= Attribution
!= Knowledge
```

`Effect` is the direct owner-native consequence established inside an effect boundary.

`Attribution` is a separate causal/credit claim about why an Outcome occurred.

This is exceptionally important for WDF1.

### Earned law EA-1

```text
Observed/owned Effect != ProofOfCausalAttribution
```

A successful API consequence does not prove the selected model caused the domain outcome in the relevant explanatory sense; a financial P&L change does not by itself identify the causal contribution of a strategy; an intervention receipt does not prove mechanism.

WDF1 must preserve this separation regardless of which causal theory eventually wins.

## 6. `UNKNOWN` in production World is epistemic, not objective chance

World retains `UNKNOWN` after response loss when an external effect may or may not have committed and owner-native evidence has not yet reconciled the original identity.

That `UNKNOWN` means:

```text
the current epistemic/evidence state does not determine which actuality obtained.
```

It does **not** mean:

```text
Reality was objectively indeterministic with chance p.
```

### Earned law U-1

```text
EpistemicUncertainty != ObjectiveChance
```

This distinction is foundational for WDF1's future chance/probability work.

## 7. `Mechanism` currently has lexical collisions inside World

The repository uses `mechanism` in at least two substantially different senses.

### M1 — authority/protocol mechanism

Receipt schemas carry fields such as:

```text
authority.mechanism
```

where the word identifies how an authority relation/evidence was produced or represented.

### M2 — causal mechanism

Capability research asks whether the observed performance is explained by:

```text
skill
environment support
authority
coordination
rule change
physical path
```

and uses mechanism decomposition to localize intervention.

These senses must not merge.

### Earned law M-1

```text
Protocol/AuthorityMechanism != CausalMechanism
```

The same lexical token does not establish a shared foundation concept.

## 8. `Cause` also has lexical collisions

Repository implementation uses language-level exception fields such as:

```text
cause: BaseException
```

while research doctrine uses causal attribution and causal mechanisms.

This looks trivial, but it illustrates a general rule:

```text
RepeatedVocabulary != SharedSemantics
```

WDF1 inventories semantic uses, not string occurrences.

## 9. `Law` currently has at least two Ordivon roles

Ordivon research frequently writes:

```text
retained law
reopen law
extraction law
```

These are **normative/methodological doctrines** created by the project after evidence/falsification.

WDF1 concerns a different question:

```text
law of nature / nomological structure
```

plus related special-science/institutional regularities.

### Earned law LEX-1

```text
OrdivonDoctrineLaw != LawOfNature
```

No vocabulary migration is permitted from the former to the latter.

## 10. `Counterfactual` is already doing several jobs

Capability doctrine asks counterfactuals such as:

```text
What if the physical path changed?
What if authority changed?
What if support/tool was removed?
What if an institution rule changed?
What if Actor assignment changed?
```

These counterfactuals differ in what is held fixed.

For example:

```text
change a physical path, hold rule system fixed
```

is not the same alternative-generation operation as:

```text
change the rule system that constitutes permission itself.
```

### Hidden assumption CF-1

A counterfactual is incomplete until we specify:

```text
what changes
what remains invariant
which laws/rules/mechanisms remain in force
which identity/continuity relations are preserved
which model generates the alternative
```

WDF1 cannot safely use a universal informal `what if?` operator.

## 11. `Intervention` is also overloaded

Current doctrine uses intervention for:

- experimental manipulation;
- removing support/tool access;
- changing a physical path;
- changing a rule/authority relation;
- changing assignment/admission mechanisms;
- policy action.

But not every action by an Agent is a causal intervention in the technical Woodward/Pearl sense, and not every formal intervention must be performed by a human/Agent.

### Earned law I-1

```text
AgentAction != CausalIntervention by default
```

and:

```text
CausalIntervention != HumanManipulation by definition
```

A future intervention theory must state the surgery/isolation semantics explicitly.

## 12. First term-separation — Actuality

`Actual` answers:

> What obtains in Reality under the specified scope/time?

Actuality does not imply necessity.

```text
Actual(X) != Necessary(X)
```

An actual event may have been avoidable/contingent under the relevant modal theory.

Likewise:

```text
Possible(X) != Actual(X)
```

WDF1 treats actuality as upstream from epistemic belief but does not assume one specific metaphysics of possible worlds.

## 13. Logical possibility

A logically possible proposition/configuration is one not ruled out by the chosen logic/consistency conditions.

This is far too weak for most World action questions.

Example:

```text
A perpetual-motion machine may be describable without direct logical contradiction
while being physically impossible under the target physical theory.
```

Therefore:

```text
LogicalPossible != PhysicalPossible
```

## 14. Metaphysical possibility — retain as an open rival notion

Philosophy often asks whether something could obtain given the essences/identity/nature of things, not merely logic and not merely actual physical laws.

WDF1-A does not assume this is a distinct objective modal layer.

It retains the question because rival law/disposition theories disagree sharply about it.

For example, dispositional essentialism may make some law-like behavior necessary given the essence of a property, whereas Humean accounts typically leave laws more contingent.

### Disposition

```text
MetaphysicalPossibility: OPEN / theory-dependent
```

## 15. Nomological / physical possibility

A condition/history is nomologically possible when it is compatible with the relevant laws of nature plus whatever background/initial/boundary conditions the theory requires.

Immediately this raises a circularity:

```text
physical possibility is often defined by laws,
while some law theories define laws through the space of physical possibilities.
```

WDF1-A marks this as **Circularity N1** rather than resolving it.

## 16. Dynamical reachability

Even if a state is nomologically possible, it may not be reachable from the current actual condition under the current dynamics/horizon.

Provisional model role:

```text
Reachable(x_now, y, dynamics, conditions, horizon)
```

Examples:

- another valid configuration exists but no allowed trajectory reaches it from here;
- a state is reachable eventually but not before the deadline;
- conservation/topology disconnects parts of state space.

Thus:

```text
NomologicallyPossible != DynamicallyReachableFromHere
```

## 17. Control / intervention reachability

An outcome can be reachable by natural dynamics but not controllably reachable by Actor A.

Conversely, an Actor may alter the system so that a target becomes reachable through intervention.

Provisional role:

```text
ControlReachable(A, current, outcome, interventionSet, horizon)
```

This is closer to current Capability than bare physical possibility.

But it already depends on what counts as an intervention and which Actor/system boundary is used.

## 18. Resource feasibility

A physically/control-reachable transition may be infeasible under available resources, capacities or requirements.

```text
Feasible_A,Q
= reachable/actionable under declared resource/quantity/compatibility constraints
```

Resource feasibility is therefore an Actor/context-relative modality, not a law of nature.

## 19. Accessibility

Current Ordivon repeatedly separates existence from current path/access.

A provider/capability can exist while no usable route/interface/materialization path currently exposes it.

```text
Accessible(A, target, path/interface, time)
```

Hence:

```text
Exists != Accessible
ReachableInAbstract != AccessibleThroughCurrentInterface
```

## 20. Institutional permission / authorization

An action can be physically possible, technically accessible and resource-feasible while institutionally forbidden.

Conversely, a valid permission can exist while the action remains physically impossible.

Therefore:

```text
Authorized != PhysicallyPossible
Authorized != Capability
Permission != PredictionThatActionWillOccur
```

Institutional modality is constituted by rule/authority systems, not by physical force.

## 21. Selectability / optionhood

Current World defines Option as a selectable feasible relation.

Thus even after feasibility/permission, a relation may not be an active decision option because:

- it is not exposed to the decision procedure;
- it violates objective/policy filters;
- its evidence is stale/UNKNOWN;
- it is dominated or excluded by the current query.

`Option` therefore belongs to decision/actionability projection, not general modality.

## 22. Epistemic possibility / openness

An event is epistemically possible for Agent A when current evidence/model has not ruled it out.

This can diverge from Reality possibility in both directions:

```text
EpistemicallyPossible but physically impossible
  — Agent does not know the relevant law/constraint.

PhysicallyPossible but epistemically ruled out
  — Agent's model is wrong/overconfident.
```

Therefore:

```text
EpistemicPossible != NomologicalPossible
```

This extends WDF0's Reality/model firewall into modality.

## 23. Probability and chance are not possibility

A proposition can be possible with probability/chance near zero, or impossible with probability zero depending on the formalism and event-space subtleties.

WDF1-A therefore freezes only the negative distinction:

```text
Possible != Probable
Probability != Possibility
EpistemicProbability != ObjectiveChance by default
```

The positive ontology of chance is deferred.

## 24. No universal linear `possibility stack`

It is tempting to write:

```text
Possible
→ Reachable
→ Feasible
→ Accessible
→ Authorized
→ Selected
→ Realized
```

WDF0-C used this as a candidate chain. WDF1-A now finds that it is **not a universal total order**.

Why:

- authorization can be defined independently of physical feasibility;
- accessibility can sometimes precede semantic feasibility evaluation;
- epistemic possibility is not nested inside physical possibility;
- institutional permission may change the very status/action kind being evaluated;
- Actor choice can change resources, constraints and future reachability.

Therefore the safer form is a **typed modal vector / conjunction of gates** rather than one universal ladder.

Provisional research notation:

```text
ModalProfile_Q(X) = {
  logical,
  metaphysical?,
  nomological,
  dynamically-reachable,
  control-reachable,
  resource-feasible,
  accessible,
  authorized/permitted,
  epistemically-open,
  chance/probability
}
```

This is a research aid, not a production schema.

## 25. Rival law theory L1 — Regularity / Humean Best-System family

Core idea:

```text
The world contains a total actual mosaic/history of non-nomic facts.
Laws are not additional governing relations.
The laws are axioms/theorems of the system that best balances
simplicity, strength/informativeness and related virtues in systematizing the mosaic.
```

Attractions for WDF1:

- ontologically economical;
- naturally separates actual mosaic from law description;
- can connect lawhood with compression/model quality;
- probabilistic/chance versions can be incorporated into a best system.

Pressure points:

- how the standards of simplicity/strength/natural predicates are fixed;
- why the best summary supports counterfactuals rather than merely describes actuality;
- whether laws have explanatory/governing force or merely systematize;
- how special-science/local/ceteris-paribus regularities relate to the best fundamental system.

WDF1-A disposition:

```text
SERIOUS RIVAL; NOT SELECTED.
```

## 26. Rival law theory L2 — Nomic necessitation / relations among universals

Armstrong-style approach:

```text
Laws are higher-order relations of necessitation/probabilification
between universals/properties.
```

This tries to distinguish genuine laws from accidental regularities by placing an objective nomic relation behind instances.

Attractions:

- gives lawhood stronger Reality-facing standing;
- explains why mere repeated conjunction is not enough;
- naturally links law with necessity/probabilification.

Pressure points:

- ontology of universals and necessitation;
- why the higher-order necessitation relation itself yields the first-order instances;
- uninstantiated laws;
- fit with global/non-dynamical/constraint-style modern physical laws;
- relation to dispositions/powers.

Disposition:

```text
SERIOUS RIVAL; NOT SELECTED.
```

## 27. Rival law theory L3 — Dispositional essentialism / powers

Bird and other dispositional essentialists propose that natural properties are essentially dispositional/potencies, with laws grounded in those essences.

Related powers approaches to causation treat causal production as manifestation of powers/dispositions in appropriate partner conditions.

Attractions:

- unifies law, possibility and causal power;
- explains why a property tends toward certain manifestations even when not currently manifested;
- maps naturally onto capability/disposition language.

Pressure points:

- finks, antidotes, masking and multi-track dispositions;
- whether all fundamental properties are dispositional;
- treatment of structural/geometrical properties;
- whether laws become metaphysically necessary in an implausibly strong way;
- whether institutional capability/permission is genuinely analogous or only structurally similar.

Disposition:

```text
SERIOUS RIVAL; NO TRANSFER FROM PHYSICAL POWER TO AGENT CAPABILITY BY ANALOGY ALONE.
```

## 28. Rival law theory L4 — Primitive governing / law-as-constraint family

Modern primitivist/constraint accounts propose that laws are fundamental nomic facts that constrain physically possible worlds/histories, without requiring laws to be temporal update rules or reducible to powers/universals.

This family is particularly motivated by candidate laws that are:

```text
all-at-once
time-symmetric
variational/global
boundary-condition-like
retrocausal/nonlocal
```

Attractions:

- directly fits WDF1's possibility-space pressure;
- does not force every law into `state(t) -> state(t+dt)`;
- potentially handles spacetime/global physical principles better than Newtonian governing metaphors.

Pressure points:

- risk of taking `law` or `physical possibility` as primitive without further explanation;
- how lawhood is distinguished from arbitrary true global constraint;
- epistemic access/discovery;
- relation to causal production and arrow/direction.

Disposition:

```text
SERIOUS RIVAL; ESPECIALLY IMPORTANT FOR WDF1/PHYSICALITY.
```

## 29. Rival law theory L5 — Capacities / local laws / model-pluralist pressure

Cartwright-style work challenges the idea that elegant fundamental equations straightforwardly describe every concrete case, emphasizing idealized models, capacities and phenomenological/local laws.

WDF1 should not treat this as one clean metaphysical theory, but as a major falsifier against:

```text
one universal exact equation directly governs every special-science event
```

Attractions:

- matches Ordivon's demand for scoped claims/dependence signatures;
- takes interfering conditions and capacities seriously;
- pressures the physical-law → biology/economics/institution transfer.

Pressure points:

- how local capacities themselves are grounded;
- relation between fundamental and phenomenological laws;
- whether plural model success implies plural law ontology.

Disposition:

```text
IMPORTANT PRESSURE/RIVAL FAMILY; NOT SELECTED.
```

## 30. Law-theory comparison exposes a first major ambiguity: `govern`

`Laws govern Reality` can mean several things:

```text
G1 temporally produce later states
G2 restrict the set of admissible histories
G3 explain regularity by necessitation
G4 summarize the actual mosaic
G5 encode essential dispositions/powers
G6 define model equations used for prediction
```

These are not equivalent.

### WDF1-A anti-law

```text
Governing != OneMechanism
```

Future law research must always unpack the sense.

## 31. Rival causation C1 — Regularity / succession

Simple regularity views associate cause with repeated conjunction/succession under suitable conditions.

Attractions:

- low ontological overhead;
- observationally grounded.

Severe pressure:

- correlation/common cause;
- direction;
- singular/token causation;
- preemption;
- prevention/omission;
- intervention and policy questions.

Disposition:

```text
TOO WEAK AS UNIVERSAL WDF1 ACCOUNT; MAY REMAIN EVIDENTIAL HEURISTIC.
```

## 32. Rival causation C2 — Counterfactual dependence family

Lewis's classic approach analyzes causal dependence through counterfactuals such as:

```text
had C not occurred, E would not have occurred
```

with later refinements for influence and chains.

Attractions:

- directly captures difference-making;
- naturally connects causal questions to alternatives;
- useful for attribution and policy reasoning.

Pressure points:

- preemption and backup causes;
- specifying which counterfactual worlds/alternatives are relevant;
- dependence on laws/similarity/background invariants;
- omissions/prevention;
- cases where cause changes probability rather than determining outcome.

Disposition:

```text
SERIOUS DIFFERENCE-MAKING RIVAL; NOT UNIVERSALLY SELECTED.
```

## 33. Rival causation C3 — Interventionist / manipulationist / structural-model family

Woodward develops causation/explanation in terms of relationships potentially exploitable under idealized interventions. Pearl's structural causal models formalize causal variables through structural equations and intervention/counterfactual semantics.

Attractions for Ordivon:

- directly useful for Agent action and policy;
- separates observation from intervention;
- supports causal effect, mediation and counterfactual queries;
- matches experimentation and Action localization.

Pressure points:

- causal variables and structural equations are model-selected;
- intervention semantics may already presuppose causal structure/isolation;
- not every natural cause is something an actual Agent can manipulate;
- actual/token causation and preemption require extra machinery;
- institutional rule change and physical intervention may require distinct constitutive background handling.

Important Woodward point for WDF1 method:

> intervention need not be anthropocentric; it is an idealized structural relation.

Disposition:

```text
EXTREMELY IMPORTANT OPERATIONAL FORMALISM; NOT EQUATED WITH WORLD ONTOLOGY.
```

## 34. Rival causation C4 — Mechanistic / productive-process family

Machamer, Darden and Craver characterize mechanisms through entities and activities organized so that they are productive of regular changes.

Attractions:

- explains how effects are produced, not merely whether variables covary;
- maps naturally to biology, engineering and failure diagnosis;
- provides decomposition for intervention localization.

Pressure points:

- may itself use causal/productive vocabulary in defining mechanism;
- mechanism boundaries and levels are selected;
- abstract/institutional/economic causes may lack obvious physical mechanism description at the chosen level;
- mechanisms can explain a phenomenon without providing a universal metaphysics of causation.

Disposition:

```text
SERIOUS EXPLANATORY/PRODUCTIVE RIVAL; NOT A UNIVERSAL ROOT BY DEFAULT.
```

## 35. Rival causation C5 — Powers / dispositional production

Mumford/Anjum and related powers accounts take causes to produce effects through dispositions/powers, often with multiple powers combining and interfering rather than strict necessitation.

Attractions:

- captures tendency/production in non-deterministic and interfering contexts;
- connects causality with capacities/dispositions;
- potentially useful for biological/chemical powers.

Pressure points:

- ontology/individuation of powers;
- masking/finks/partners;
- relation to law and probability;
- risk of reifying Agent capability metaphorically as the same kind of power.

Disposition:

```text
SERIOUS RIVAL; NO AUTOMATIC AGENT/INSTITUTION TRANSFER.
```

## 36. Rival causation C6 — Probabilistic causation

On probabilistic approaches, causes may change probabilities/chances rather than determine effects.

A minimal candidate form is:

```text
P(E | intervention/exposure C, context)
  differs from
P(E | comparison, context)
```

But probability raising alone is vulnerable to confounding, selection and Simpson-type reversals.

WDF1 therefore distinguishes:

```text
probabilistic association
probabilistic causal effect
objective-chance production
```

These are not yet unified.

Disposition:

```text
REQUIRED FOR STOCHASTIC DOMAINS; THEORY DEFERRED UNTIL CHANCE IS SEPARATED.
```

## 37. Rival causation C7 — Causal pluralism

WDF0 already found that `cause`, `constraint` and `constitution` answer different questions. WDF1-A now sees internal diversity even within causation:

```text
production
mechanism
difference-making
control/intervention
probability change
actual/token attribution
```

A pluralist possibility is that no single reductive relation captures every legitimate causal claim.

Danger:

```text
unconstrained pluralism = give up on shared law
```

Requirement if pluralism survives:

- typed causal query;
- explicit relation among types;
- cross-domain invariance where earned;
- no contradictory attributions under same scope.

Disposition:

```text
SERIOUS META-RIVAL; NOT A LICENSE FOR ARBITRARY CAUSE LABELS.
```

## 38. Circularity audit — laws and possibility

### N1

```text
PhysicalPossible(X)
= X compatible with laws
```

but constraint/primitivist views may say:

```text
Law = fundamental constraint on physical possibilities
```

This is not automatically vicious, but it is a foundational circle if both are offered as reductions.

WDF1 must decide whether one side is primitive, jointly defined, or grounded elsewhere.

## 39. Circularity audit — laws and counterfactuals

Counterfactual truth commonly depends on holding laws fixed while changing antecedent facts.

But counterfactual-support is also frequently used to distinguish laws from accidental regularities.

```text
Law → counterfactual support
Counterfactual support → evidence/criterion for law
```

Again: potentially explanatory interdependence, but not a clean reduction without further structure.

## 40. Circularity audit — dispositions and counterfactuals

Classic conditional analysis tries:

```text
x is fragile
iff
if x were struck under suitable conditions, x would break
```

Finks, antidotes/masks and multi-track dispositions pressure simple counterfactual reduction.

If counterfactual truth itself depends on dispositions/laws, then:

```text
Disposition -> Counterfactual -> Disposition
```

may be circular.

WDF1 therefore cannot casually define capability/power as `what would happen if triggered` without auditing masks/background conditions.

## 41. Circularity audit — causation and intervention

Interventionism may define:

```text
X causes Y when an appropriate intervention on X changes Y.
```

But `appropriate intervention` is often specified partly by requiring that the intervention change X while breaking/excluding other causal paths into X and not directly affecting Y except through X.

This uses causal vocabulary in the intervention definition.

Woodward explicitly treats the account as potentially illuminating without requiring reductive elimination of all causal notions.

### WDF1 lesson

```text
Non-reductive circularity may be acceptable if roles are independently constrained,
but must not be sold as primitive-free reduction.
```

## 42. Circularity audit — mechanism and causation

If:

```text
Mechanism = organized productive activities
```

and:

```text
Cause = relation realized by mechanism
```

then `productive` may already be causal.

Mechanistic theories can still be explanatory without being reductive metaphysics.

WDF1 must separate:

```text
mechanism as explanatory decomposition
from
mechanism as attempted definition of causation.
```

## 43. Circularity audit — chance and probabilistic law

Possible circles include:

```text
ObjectiveChance = probability assigned by the true probabilistic law
ProbabilisticLaw = law containing objective chances/probabilities
```

Humean best-system views, propensity views and governing-law views break or embrace this relation differently.

WDF1-A cannot resolve chance before law/modality architecture is clearer.

## 44. Circularity audit — Capability and cause

Current Ordivon:

```text
Capability = ability to cause/obtain transition
```

Yet Agent intervention questions may be framed as:

```text
What causes capability / how does capability cause outcomes?
```

Without typing, `Capability` can become both explanans and a summary of causal reachability.

### Earned anti-law

```text
CapabilityLabel != IndependentCausalMechanism
```

A capability claim may summarize supported counterfactual/control reachability without explaining why it holds.

## 45. Circularity audit — institution as `causal role`

Current Capability doctrine deliberately calls Environment and Institution causal roles for counterfactual diagnosis.

WDF0-C/D later established:

```text
Cause != Constitution
```

WDF1-A therefore tightens the doctrine conceptually:

- institutional rule/status may **constitute** authority/permission;
- implementation/enforcement/incentive channels may **cause** behavior/outcomes;


## 52. Deep result 1 — `modality` is not one axis

WDF1-A's strongest result is analogous to WDF0-E's result for `level`.

Just as:

```text

```

collapsed several independent axes, so:

```text
more/less possible
```

can collapse several independent modal relations.

A physically possible but unauthorized action and an authorized but physically impossible action show that institutional and physical modality do not live on one total ordering.

Therefore WDF1 requires a **typed modal architecture** before it can evaluate law/causal theory coherently.
