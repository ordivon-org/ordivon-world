# WDF0-A — Current Primitive & Hidden Assumption Inventory

Status: complete for WDF0-A; WDF0-B is the next admitted sub-round.

## 0. Question

Before deciding what a World or Reality is, what ontology has Ordivon already accumulated implicitly across its mature domains?

WDF0-A treats current code and frozen domain foundations as evidence, not as truth about Reality. The purpose is to expose hidden commitments, classify vocabulary by truth role, identify cross-domain convergence and isolate the largest unsupported assumptions.

## 1. Evidence base

Primary internal comparison set:

- `ordivon-world/ARCHITECTURE.md`
- Runtime Foundations v1 (`RF0–RF16` compact constitution)
- Human HF0 problem-space reconstruction and HF1 boundary/identity round
- Human HF0–HF18 cycle closeout
- Finance Foundations v1 and FR0 problem-space reconstruction
- Ordivon Computing core foundations
- Game development/world-reality boundary documents
- current World source vocabulary and prior W5 / Sense-Connect-Act research

A lexical matrix was used only as a diagnostic. Frequency is not ontological importance. It is useful mainly to expose asymmetries: `state` is widespread, while `space`, `causality`, physicality and explicit `environment` theory are sparse.

## 2. Main discovery — Ordivon already contains a latent meta-grammar

Independent domain research repeatedly converges on the following separations:

```text
Reality
  != Observation
  != Evidence
  != Representation / Projection
  != Belief / Claim / Model

Reality
  is queried through
  Boundary / Scope / Context / Scale / Timescale

Actor / Agent
  relates to
  Resource / Option / Capability / Authority
  then
  Proposal / Decision / Action / Realization / Effect
  then
  Observation / Evidence / Update

Identity / Currentness
  are typed and time-bound rather than timeless labels.
```

This grammar was not designed centrally. Runtime, Human, Finance, Computing, Game and World reached parts of it independently through falsification. That convergence is evidence that WDF0 should investigate it, but not yet evidence that every item is a Reality primitive.

## 3. Primitive-family inventory

### 3.1 Reality

Current role:
- explicit upstream referent in Runtime, Human, Finance and Computing;
- repeatedly separated from observation, evidence and model;
- only weakly defined positively.

Disposition for WDF0:
- retain as the provisional name for what models, observations and actions concern;
- do not yet equate Reality with one object collection, state space, physical substrate or total information structure.

### 3.2 World / Environment

Current role:
- `ordivon-world` uses World primarily as an engineering boundary between Host-owned work and independently authoritative environments;
- Game uses world/reality as an authoritative domain state distinct from cognition/presentation;
- Human uses environment as one coupled projection;
- Runtime treats external Reality as outside generic Runtime ownership.

Problem:
- `World`, `Reality` and `Environment` are not yet cleanly separated.
- Environment is usually actor/system-relative; Reality is intended to be broader.

Disposition:
- unresolved; must be attacked in WDF0-B/D.

### 3.3 Projection / Representation / Model / Context

Current role:
- Human HF0 explicitly makes projection a first-class research discipline;
- Finance v1 treats many familiar nouns as query-relative projections;
- Runtime separates Reality, Observation, Evidence and Projection;
- Computing defines the world model as a current compressed claim set, explicitly downstream of Reality.

Strong cross-domain anti-law:

```text
UsefulProjection != CompleteOntology
```

Disposition:
- strong candidate meta-coordinate;
- not obviously an ontic constituent of Reality itself.

### 3.4 Boundary / Scope

Current role:
- Human HF1 demonstrates multiple legitimate boundaries for one human: organism, task-system, cognitive, legal and other typed boundaries;
- Runtime uses enforced/scope boundaries and refuses scope inflation;
- World preserves owner boundaries and refuses global authority/state ownership;
- Finance uses actor/boundary/query-relative positions and portfolios.

Strong cross-domain lesson:

```text
UsefulBoundary != UniqueNaturalBoundary
```

But some boundaries are physically or institutionally consequential, not arbitrary model cuts.

Disposition:
- central WDF0 problem, not yet a universal primitive.

### 3.5 Relation / Dependency / Coupling

Current role:
- Finance FR0 found the surviving structure more relational than object/product based;
- Human capability is explicitly actor–outcome–condition relational;
- World effect paths, presence, connection and transfers preserve relationships without centralizing owners;
- Runtime has resources/dependencies and open-system relations.

Disposition:
- unusually strong cross-domain candidate;
- must be tested against object-first and process-first rivals rather than promoted by convergence alone.

### 3.6 Entity / Object / Property

Current role:
- surprisingly weak as universal concepts;
- World has `Entity Migration`, but explicitly refuses a global Entity/Presence ontology;
- Human uses entity/object only locally and rejects single-noun identity reductions;
- Finance rejects product/object names as primitives.

Important negative evidence:
- Ordivon has not converged on `World = set of entities with properties`.

Disposition:
- unadmitted as universal roots.

### 3.7 State

Current role:
- ubiquitous across World, Runtime, Human, Finance, Computing and Game;
- useful for owner-native current projections, dynamic models and control.

Risk:
- software/state-machine vocabulary may be overgeneralized to Reality.
- state can mean thermodynamic state, legal state, world state, belief state, process state or stored record, which are not automatically one ontological kind.

Disposition:
- high-priority suspect in WDF0-B/C.

### 3.8 Event / Process / Operation / Trajectory

Current role:
- Runtime rigorously distinguishes Operation from Attempt/Realization/Effect;
- Human development/history is process-like;
- World uses trajectory for cross-World commitments;
- event/process language is much less dominant than state language.

Problem:
- Ordivon may be state-biased rather than process-complete.
- `Operation` is explicitly Runtime-local and must not become a universal World primitive.

Disposition:
- process/event roots remain live rivals.

### 3.9 Change / Dynamics / History

Current role:
- Human HF6 makes history-dependent parameter change constitutive;
- Human and Game preserve trajectory/history as causally relevant;
- Computing says practice changes the world model;
- Runtime owns bounded realization/recovery histories;
- World preserves historical evidence but separates history from currentness.

Strong lesson:

```text
CurrentState cannot always be understood without History.
```

Disposition:
- major candidate family, underdeveloped at World level.

### 3.10 Time / Currentness

Current role:
- World separates provider occurrence, World availability and Host admission time;
- Runtime has explicit ordering/concurrency/causality foundations;
- Human and Finance make timescale/horizon central;
- currentness repeatedly changes action validity.

Problem:
- these are local temporal distinctions, not a World theory of time.

Disposition:
- cross-cutting coordinate; foundation status unresolved.

### 3.11 Space / Location / Topology

Current role:
- largely implicit through endpoint, path, body, network, venue and physical location;
- far less theorized than time/state.

Gap:
- no World-level account of location, distance, containment, adjacency, region, topology or reference frame.

Disposition:
- major uncovered foundation region.

### 3.12 Identity / Sameness / Persistence

Current role:
- Runtime uses exact semantic identity and replay identity;
- Human HF1 rejects one universal sameness relation and uses typed persistence criteria;
- World separates trajectory identity, source/destination identity and current presence;
- Finance distinguishes instrument/position/market roles from labels.

Strong anti-law:

```text
Same_X != Same_Y
```

Disposition:
- typed persistence is strongly supported; a single universal Identity predicate is not.

### 3.13 Observation / Evidence / Claim / Belief / Truth

Current role:
- one of the strongest convergences in Ordivon;
- Runtime freezes `Reality != Observation != Evidence != Projection`;
- Human separates first-person/third-person evidence, report and experience;
- Finance separates Market Data from Market Reality and Evidence from Belief;
- World provider success remains observation rather than Task truth/completion.

Disposition:
- epistemic grammar is mature relative to ontic grammar.
- WDF0 must avoid confusing an epistemology of access with an ontology of Reality.

### 3.14 Authority / Right / Permission / Normative Status

Current role:
- Runtime and World aggressively preserve authority locality;
- Human separates descriptive, legal, moral and institutional status;
- Finance decomposes rights, claims, obligations and powers.

Problem:
- authority is clearly real for action possibility in institutional systems but is not obviously a universal property of non-agentic physical Reality.

Disposition:
- institutional/agentive foundation family, not current universal root.

### 3.15 Actor / Agent / Subject / Body

Current role:
- Human proves these are different projections;
- World W5 work separates Subject, Body, owner and current relation;
- Finance positions are actor-relative;
- Game uses agents as optional participants, not as the definition of game reality.

Disposition:
- domain-important but World must remain meaningful in an agent-free universe.
- agent-centric ontology is rejected as universal.

### 3.16 Resource / Option / Capability

Current role:
- Finance treats resources as upstream World substrate;
- Human capability is actor–outcome–condition relational, not an internal possession;
- Computing separates capability from consequence;
- World projects current capabilities without converting them into authority.

Likely relation:

```text
Reality condition
  + Actor / Goal / Outcome class
  + Access / Control / Constraint
  -> Resource / Option / Capability projection
```

Disposition:
- high-value World research family;
- strongly actor/goal/context relative and therefore unsafe as context-free object types.

### 3.17 Action / Realization / Effect / Consequence

Current role:
- Runtime sharply separates Proposal, Operation, Attempt/Realization, Effect and Observation;
- World separates selection/current capability/action authority/effect evidence;
- Human separates decision, action, control and realized outcome;
- Computing treats durable Effects as commitments.

Strong lesson:

```text
Intent != Action != Realization != Effect != Observation
```

Disposition:
- mature agent/open-system grammar; causality beneath the chain remains under-theorized.

### 3.18 Information / Signal / Data / Representation

Current role:
- Human, Finance, Game and Media rely on these distinctions;
- World engineering architecture barely theorizes them.

Gap:
- no World foundation tells whether information is intrinsic, relational, observer-relative, semantic, causal or multiple typed notions.

Disposition:
- major unresolved bridge between Media, Human, Computing and World.

### 3.19 System / Organization / Institution

Current role:
- Human and Finance use systems, organizations and institutions as causally consequential higher-level structures;
- Computing speaks in layered owners/systems;
- World does not yet provide a system/organization ontology.

Gap:
- no principled rule distinguishes a real system from a convenient model boundary.

Disposition:
- high-priority scale/composition problem.

### 3.20 Scale / Timescale

Current role:
- Human HF0 explicitly requires scale and timescale coordinates;
- other domains often imply scale but do not formalize it;
- cross-layer Ordivon routinely moves from process to service to organization to market/institution.

Disposition:
- likely model coordinates with potential ontic consequences through organization/emergence;
- not mere metadata by assumption.

## 4. Hidden commitments that already look durable

WDF0-A finds ten cross-project commitments stronger than any single positive ontology:

1. **External Reality commitment** — models and observations are answerable to something they do not create merely by representing it.
2. **Epistemic separation** — Reality, observation, evidence, representation and belief/claim are not interchangeable.
3. **Projection plurality** — one useful model/view need not be the unique complete ontology.
4. **Boundary typing** — legitimate boundaries depend on question, owner, scale, function or authority; no universal boundary is assumed.
5. **Temporal qualification** — historical evidence does not automatically grant current truth/capability/authority.
6. **Typed identity** — sameness requires a criterion; labels or IDs alone do not settle persistence.
7. **Authority locality** — knowledge/action/commitment authority is owned locally and does not arise from aggregation alone.
8. **Open-world non-closure** — failure to observe, missing receipt or incomplete model does not prove nonexistence/nonoccurrence.
9. **Relational capability** — resource/capability/actionability depends on actor, outcome, access, conditions and constraints.
10. **Action-chain separation** — proposal, decision, realization, effect and observation are distinct truth roles.

These are currently better supported than claims such as `Reality is made of Objects` or `Reality is a State Machine`.

## 5. Hidden biases exposed by the audit

### 5.1 State bias
`state` is ubiquitous because software, games, finance and control systems expose state surfaces. This is practical evidence, not proof that state is ontologically primary.

### 5.2 Digital ontology bias
World engineering is strongest where reality arrives as request IDs, schemas, receipts, artifacts, owners and trajectories. Those are robust interfaces to external reality, not a theory that reality itself is message-passing software.

### 5.3 Agent-centric bias
Resource, capability, authority, action and observation dominate Ordivon because Ordivon is an acting system. Reality must still admit stars, rocks, fluids and pre-agent history.

### 5.4 Weak physicality
Matter, energy, entropy, field, force, chemical transformation and thermodynamic openness are almost absent from the current shared grammar.

### 5.5 Weak spatial theory
Network path and endpoint are not substitutes for a theory of space, topology, containment and reference frames.

### 5.6 Weak causal ontology
Ordivon has excellent effect/recovery semantics and Human causal reasoning, but the underlying meanings of cause, mechanism, enabling condition, constraint, prevention and feedback are not yet World foundations.

### 5.7 Weak scale/composition theory
Human and Finance already rely on organism, firm, institution, market and other macro structures. Ordivon lacks a general account of part/whole, coarse-graining, hierarchy, organization and emergence.

### 5.8 Social/institutional under-integration
Human and Finance show that rights, rules, organizations, norms and institutions alter real options and outcomes. World does not yet explain how these relate to physical/digital substrate without reducing them to metadata or treating them as free-floating facts.

### 5.9 Information ambiguity
Signal/data/information/evidence/representation/meaning are spread across Media, Human and Finance but lack one World-level separation grammar.

### 5.10 System/environment ambiguity
`system` and `environment` are used heavily enough to matter but weakly enough that no global criterion tells us what makes a boundary intrinsic, emergent, functional or merely analyst-chosen.

## 6. External pressure check

WDF0-A does not select an external ontology, but established rivals prove that several root commitments are genuinely live:

- Basic Formal Ontology explicitly divides top-level entity structure into continuants and occurrents and contains objects, processes, spatial/temporal regions and boundaries. This is evidence that an object/process upper ontology can be made rigorous, not evidence that BFO is Reality itself.
- Process philosophy supplies a serious dynamic-first rival in which becoming/process is ontologically primary rather than secondary change of static things.
- Markov-blanket work formalizes system boundaries statistically and shows that such boundaries can be nested, scale-dependent and non-coextensive with ordinary biophysical boundaries.
- causal-emergence work provides mathematical examples where coarse-grained macro dynamics can change measured causal informativeness, warning against treating scale as presentation-only metadata.

These rivals are sufficient to reject premature commitment to an object-only, process-only, state-only or fixed-boundary World model.

## 9. Exact residual entering WDF0-B

The inventory does not reveal one obvious primitive. It reveals a competition among root grammars.

The next question is therefore not `What is Entity?` but:

> Which root grammar can reconstruct the greatest fraction of these cross-domain distinctions with the fewest primitive commitments and the fewest destructive collapses?

WDF0-B will compare at least:

1. object/substance-property models;
2. event/process models;
3. relational/structural models;
4. state-space/dynamical models;
5. system/environment models;
6. constraint/possibility models;
7. interaction/causal models;
8. plural/family-resemblance models with no single root noun.

Each rival must reconstruct physical, biological, cognitive, social, institutional, computational and Agent-coupled cases before it earns foundation status.

## 10. WDF0-A closeout

WDF0-A is complete when the following is preserved:

```text
Ordivon already has a latent world grammar,
but it is primarily a grammar of disciplined access, projection, agency and authority.

Its epistemic and operational distinctions are much more mature
than its ontology of physicality, space, dynamics, causality, scale and composition.

Therefore no current engineering noun is admitted as the root of World.
```

WDF0-B is admitted. WDF1 remains UNKNOWN.
