# 42. Preliminary matched-case battery

WDF4-A does not yet perform the full matched tournament, but minimal cases already prove that several simple identifications fail.

## M1 — common cause

```text
storm pressure state → barometer reading
storm pressure state → rain
```

Barometer/rain association does not establish barometer→rain cause.

Result:

```text
Association != Cause
```

## M2 — preemption / backup

Two sufficient potential causes exist; one acts first and preempts the backup.

Simple but-for dependence on the actual cause can fail while actual-cause intuition/structural accounts still distinguish the preemptor.

Result:

```text
ButForDependence != AllActualCausation
```

## M3 — randomized population effect vs token attribution

An intervention changes population risk, but one treated individual's outcome may still have occurred without treatment or may have multiple sufficient causes.

Result:

```text
PopulationCausalEffect != TokenActualCause
```

## M4 — catalyst / enabling condition

Catalyst, reactants, temperature and other conditions can jointly alter reaction dynamics; which is called cause/enabler depends on query/contrast while mechanistic roles differ.

Result:

```text
Cause/Enabler vocabulary requires query + mechanism typing
```

## M5 — prevention

Safety interlock blocks a transition that otherwise would occur.

Result:

```text
PositiveProductionModelAlone is under pressure
```

## M6 — omission

A required heartbeat is not sent and a lease expires under an operative timeout protocol.

Result:

```text
negative causal claim can be operationally precise
without first admitting an Absence entity
```

## M7 — institution

A valid rule/procedure constitutes authority status; enforcement communication/incentives then causally influence behavior.

Result:

```text
Constitution != CausalInfluence
```

## M8 — software propagation

Configuration defect causes one service failure which propagates through dependencies to a downstream outage.

Result:

```text
Direct cause != causal path ancestor
```

unless query/model semantics intentionally use a broader cause relation.

## M9 — Agent mediation

A model recommendation leads a Human to choose a tool action that produces a provider effect.

Result:

```text
influence / decision / authority / execution / attribution must separate
```

## M10 — reciprocal organism/environment feedback

Organism alters environment; altered environment changes later selection/behavioral pressures; those changes alter later organism/environment states.

Result:

```text
feedback can be causally directional after indexing
without erasing organism/environment boundary
```

# 65. Final compressed judgment

WDF4-A finds that Ordivon's causal problem is not the absence of a `Cause` noun. It is the repeated compression of several different layers and query types into causal vocabulary.

Current production is intentionally safe because its `effect`, `outcome`, `mechanism` and exception `cause` fields are operational/lexical notions rather than a persisted causal ontology. Current research doctrine, however, already depends on genuine causal distinctions: exposure assignment versus exposure effect, current expression versus capability production, intervention effect versus mechanism/attribution, source versus transported causal claim, and time-indexed feedback.

The first-principles reconstruction is therefore:

```text
CausalRealityClaim
!= CausalQuerySemantics
!= Identification/Evidence
```

and:

```text
CausalEffect
!= ActualCause
!= Mechanism
!= Control
!= Explanation
!= Attribution
```

while:

```text
Many query types != proven causal pluralism
One formalism != proven causal monism
```

The strongest hidden assumptions rejected or withheld are binary-relata simplicity, temporal precedence, universal locality, simple but-for reduction, Actor manipulability, probability raising, necessity/sufficiency, universal transitivity, model-independent directness, causal-graph ontology, primitive absence for omissions and extra macro force for macro causal usefulness.

The remaining problem is now empirical/conceptual rather than lexical: when matched cases hold the surrounding Reality fixed, which candidate causal structures track the verdict and which fail? That is the exact task of WDF4-B.
