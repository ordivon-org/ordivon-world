## Why `Capability Field` is not a new primitive

World already has the needed static ingredients:

```text
ResourceFor(actor, aspect, transition, as_of)
ActionableResourceFor(... demand ...)
Requirements + Assignments + native Constraints
Option
Capability = boundary-relative supported transition ability
```

Therefore a useful analytical query can be written as:

```text
CapabilityProjection(actor, target_transition, demand, as_of)
```

without persisting a `CapabilityField` entity or duplicating owner-native state. CF1 must first demonstrate a residual decision that current projections cannot answer before any stronger representation is considered.

## Why Institution remains distinct from generic Environment — but only as a causal role

Institutional state can be part of an actor's realized environment. The distinction survives deletion only where the question asks a counterfactual about **durable rules/processes** that alter recurrent access, authority, admissible transitions, incentives, enforcement, ownership/appropriation, coordination, recovery or exit.

This does **not** earn one universal Institution record. The relevant facts remain owner/domain native.

## Strongest surviving research burdens

### 1. Dynamic capitalization

M4 has 9 incremental frozen cases over the transition-topology decomposition. The central question is:

```text
did environment/support only change current expression?

or did repeated exposure/feedback change later actor state?
```

Human retained-capability work, World R7 signed feedback, dynamic skill-formation theory and randomized neighborhood exposure all pressure this distinction. No universal actor update equation is earned.

### 2. Selection / sorting

M5 has 6 incremental cases. This is an identification problem rather than an ontology object:

```text
actor → environment choice
institution → actor selection
common cause → both exposure and outcome
```

Without this distinction, environment/institution correlations can be mistaken for causal effects.

### 3. Coevolution

M6 has only 2 incremental cases after correcting a false-positive recursive-Knowledge case. This is intentionally weak evidence. The surviving pressure concerns rules/resources/power/population changing one another over long horizons. CF6 must decide whether this transports outside political-economy/domain-specific models.

## External triangulation result

External evidence does not support one simple “institution beats individual” law. Instead it raises four independent pressures:

1. institutions can causally shape constraints/incentives and may evolve with resource/power distributions;
2. randomized environmental exposure can have duration/age-dependent long-run effects;
3. assignment into environments can itself be changed by search/information frictions;
4. causal interaction and variance claims are highly sensitive to identification, endogeneity and measurement.

This is exactly why CF separates M2 interaction, M4 state production and M5 assignment/identification instead of collapsing them into a context coefficient.

Otherwise CF0 is closed and should be consumed rather than expanded.
