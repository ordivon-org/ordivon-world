# CF6 — Capability–Institution Coevolution

Status: **COMPLETE**

## 1. CF6 starts weak on purpose

CF0 gave coevolution only two incremental frozen cases beyond selection/sorting. CF6 therefore does not assume a grand feedback model exists.

It asks the narrower question:

> When does treating institutions/resources/environments as exogenous trajectories produce a decision error because earlier Actor actions/outcomes themselves change the later trajectory?

## 2. Five feedback families, not one loop

CF6 finds at least five useful families:

```text
resource → power → rule
capability → opportunity → exposure → capability
externalization → joint output → practice/dependence → later tool/recovery policy
Knowledge → search/acquisition → Resources/Options → evidence
institution ↔ human-capital/development competing directions
```

Their mechanisms, units, clocks, owners and evidence are materially different.

Therefore recurrence of the arrow shape does not earn a `CoevolutionEngine`.

## 3. Political-economy pressure

Acemoglu–Johnson–Robinson explicitly model political institutions and resource distribution as dynamic state variables that influence political power and future institutions.

Acemoglu's 2025 institutions/technology framework continues to emphasize interaction among institutions, technological possibilities, distributions and institutional change.

But Glaeser and coauthors provide a strong competing interpretation in which common institutional measures/identification can overstate institution-first causality and human capital/policy may be more basic in some development comparisons.

CF6 uses the disagreement as evidence **for preserving competing directions**, not for choosing one universal loop.

## 4. Ordivon already has smaller feedback evidence

World R7 already showed:

```text
Capability
→ better Resource acquisition
→ more Options
→ more learning/effects
→ possibly more Capability
```

and the opposite-sign possibility:

```text
external capability ↑
→ internal practice ↓
→ independent skill ↓
→ dependence ↑
```

R7 correctly requires Attribution before either becomes a causal flywheel claim.

CF6 generalizes only that proof rule.

## 5. M6 gate

A coevolution model is justified only when all three hold:

1. the future environment/institution/resource/Actor trajectory is endogenous to prior outcomes at the decision horizon;
2. that feedback changes a prediction or intervention relative to treating the trajectory as externally supplied;
3. direction/mechanism has evidence beyond repeated temporal adjacency.

If the institution is effectively fixed over the current horizon, M4/M5 is enough.

## 6. Result

`Capability–Institution Coevolution` survives only as:

> **a family of owner-native, time-indexed causal hypotheses whose feedback directions must be separately identified.**

The shared reusable law is negative:

```text
repeated correlation
!= feedback loop

temporal order
!= causal direction

shared arrow shape
!= shared mechanism
```

No universal coevolution graph, Power scalar or institution-first causal doctrine is earned.
