# CF7 — Causal Transport Across Actors, Environments and Domains

Status: **COMPLETE**

## 1. Shared structure is not automatic transport

CF1–CF6 repeatedly found the same semantic shapes in Human, Agent systems, World resources and institutions. CF7 asks when a conclusion learned in one source setting may constrain a target setting.

The default is deliberately conservative:

```text
same vocabulary
!= same mechanism

same graph shape
!= same causal parameter

source causal effect
!= target causal effect
```

This matches existing World R10 evidence-transport doctrine: source evidence may travel, but target truth does not travel automatically.

## 2. Minimum transport question

A useful transport analysis asks:

```text
source claim / source population / source intervention
        ↓
what mechanism or causal relation is believed stable?
what differs in the target?
which moderators/selection processes can change the effect?
        ↓
target claim / target decision
        ↓
what target evidence is still required?
```

CF7 treats this as a reasoning envelope, not a persisted contract.

## 3. Transport postures

These are categorical postures, not a quality score.

### Structural analogy only

The source shows a useful distinction but not the target mechanism.

Example:

```text
Agent Tool grant changes feasible actions
→ proves capability != authority structurally
→ does not prove a Human legal/institutional effect size
```

### Mechanism-supported transport

There is evidence that the causal mechanism relevant to the target is shared, while named differences are bounded.

### Calibrated target transport

Source evidence supplies the mechanism/prior and a bounded target probe tests the important moderators or changed mechanisms.

### Target-native evidence

The target decision is answered by evidence generated under the target owner/population/conditions. This does not make source evidence useless; it changes its role to mechanism, prior, comparison or negative-transfer support.

## 4. Formal causal-transport pressure

Bareinboim and Pearl's transportability work is useful because it makes a key requirement explicit: transfer depends on assumptions about **which causal mechanisms are shared and which differ between source and target**. Their selection-diagram framework and later meta-transportability results show that some target effects are recoverable from combinations of source experimental and target observational information, while others are not without additional assumptions.

CF7 imports the question structure, not a universal graphical engine for Ordivon.

## 5. Human ↔ Agent transport boundary

Controlled Agent systems are valuable structural laboratories because weights, Tool grants, Context, recovery substrate and owner boundaries can often be changed cleanly.

They can strongly test claims such as:

```text
capability != authority
joint-system capability != component capability
support removal can expose recovery dependence
current Context can change action without changing model weights
```

But they do not establish Human learning, motivation, fatigue, preference, social legitimacy or long-horizon deskilling mechanisms.

Human claims require Human evidence or an explicit transport argument.

## 6. External human evidence ↔ Ordivon Human

The reverse boundary is also real.

A randomized education result can constrain Human hypotheses, but it does not automatically answer:

- this person's learning policy;
- professional multi-year skill retention;
- another subject/domain;
- a materially different AI interaction policy;
- a recovery requirement under Ordivon work.

The correct default remains:

```text
external evidence
→ mechanism / moderator / boundary analysis
→ natural target dogfood
→ bounded residual direct probe if decision-relevant
```

## 7. Cross-owner Ordivon transport

Repeated semantic inequalities can transport more readily than mechanisms:

```text
capability != authority
historical truth != current applicability
performance != retained capability
assignment != exposure effect
shared semantics != shared machinery
```

But currentness, authority, identity and recovery mechanisms remain owner-native.

This is the same pattern OFR2 found: the strongest shared object is often a **question or inequality**, not an implementation.

## 8. CF7 result

A causal conclusion may be transported only relative to an explicit source–target comparison. The reusable minimum is:

> **State the source claim and target claim separately; name the mechanism/invariance being transported, the source–target differences that could break it, the evidence supporting that invariance, and the target probe or residual uncertainty. If the changed mechanism is decision-relevant and untested, preserve UNKNOWN.**

No universal TransportContract service, transport score or automatic analogy engine is earned.
