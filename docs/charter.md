# Ordivon Edge Charter

Status: active working definition

Ordivon Edge is the distributed external presence and execution fabric for deploying observable, disposable, and policy-scoped Agent bodies across heterogeneous environments.

The current Cloudflare Worker, Browser Run, Fetch, R2, receipt, and release implementation is the production profile. It does not define the project's eventual capability ceiling.

## Responsibility

Edge owns remote Node identity, class, provider, source or image, capability descriptor, policy revision, resource lease, lifecycle, execution receipt, Artifact provenance, reconstruction inputs, and failure or destruction evidence.

It supports three profiles:

- production: narrow capabilities, conservative policy, persistent service, and bounded budgets;
- research: writable temporary bodies, broader tools, longer execution, and complete capture;
- adversarial range: high-autonomy disposable nodes, range-local persistence, Agent-created tools, multi-stage work, and whole-environment destruction.

## Capability and consequence

A research or adversarial body may be internally powerful. Its capability profile remains separate from the external resources, identities, networks, and targets it can affect. Production and adversarial profiles do not share credentials or implicit authority.

## Boundary

Edge supplies where and through which body an Agent acts. Security owns campaign objectives and verdicts; Link owns connectivity; Host owns cognition and Tasks; Runtime owns trusted-local execution.

The cross-project source charter is maintained in `ordivon-computing/research/charters/EDGE-CHARTER-002.md`.
