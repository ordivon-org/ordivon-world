# Network Observation Charter

Status: active source-native observation module inside Ordivon World

This module collects and presents bounded, method-bound network observations. It owns probe definitions, target registry validation, collection identity, timing/failure measurements, reduced route state, sanitized history, and loopback presentation.

It does not own Task connectivity requirements, routing decisions, participant authority, provider execution, Effect recovery, or World binding. Host and domain owners decide how observations affect work.

Legacy Link vocabulary and Network World/transport research are compatibility and historical surfaces. They do not establish a separate Link layer.
